# TS Proxy

Прокси-сервис с шифрованием трафика: Telegram-бот продаёт подписку и обслуживает клиентов, сайт `ts-proxy.com` рассказывает о сервисе и хранит инструкции и документы.

## Где что лежит

| Папка | Что внутри |
|---|---|
| `bot/` | Telegram-бот: код, тесты, тексты бота. Как запустить — `bot/README.md` |
| `web/` | новый сайт на Next. Как запустить — `web/README.md` |
| `site/` | старый сайт на чистом HTML — удаляем после переключения домена на новый |
| `config/` | общий конфиг сервиса, его читают бот и сайт: тарифы и цены (`tariffs.yaml`) |
| `ops/` | скрипты серверов: служба бота, бэкапы панели Remnawave, защита серверов |
| `docs/` | документы по серверу и запуску, правила для агентов |
| `prototypes/` | черновые прототипы (страница подписки) |
| `.scratch/` | планы, спецификации и задачи: `tsproxy-bot/` — бот, `tsproxy-site/` — сайт |

Словарь терминов — `GLOSSARY.md`. Сервис везде называется «прокси», слово «VPN» не используем.
