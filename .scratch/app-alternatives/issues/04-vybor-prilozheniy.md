# Выбор приложений по устройствам

Type: grilling
Status: resolved
Blocked by: 01, 02

## Question

По итогам исследований — какие приложения (до 4 на устройство, включая Happ и v2RayTun там, где они есть) идут в проверку на iPhone/iPad, Android, Windows, macOS, Linux, и в каком порядке их показывать клиенту (основное → запасное → альтернативы)?

## Comments

Ссылки — на официальный сайт happ.su, рядом инструкция, как правильно скачать оттуда (Android — APK, ПК — файлы с GitHub через сайт). **iPhone/iPad — инструкция по смене региона App Store, чтобы скачать Happ.** Остальные приложения агент описывает, владелец выбирает.
- 2026-11-09, владелец: «всё в целом да; если будут проблемы — что-то уберём, что-то перепишем».

## Answer

2026-11-09. Happ — основной везде, ссылки на официальный сайт happ.su с инструкцией, как оттуда правильно скачать.

| Устройство | 1. Основное | 2. Запасное | 3–4. Ещё варианты |
|---|---|---|---|
| iPhone/iPad | Happ | OneXray | Clash Mi, Karing (оба — только если пройдут проверку) |
| Android | Happ (APK с happ.su; инструкция «разрешить установку из неизвестных источников») | v2RayTun (Google Play) | Hiddify, OneXray |
| Windows | Happ | v2RayTun (если в проверке найдём официальный источник; иначе — OneXray) | Hiddify, v2rayN |
| macOS | Happ (файл с GitHub через happ.su) | OneXray (российский Mac App Store) | Hiddify, v2rayN |
| Linux | Happ | Hiddify | v2rayN, Throne |

- **Happ на iPhone:** кто уже когда-то ставил Happ и видит его в своих покупках App Store — ставит оттуда (проверить, что из «Покупок» скачивается с российского аккаунта, — задача «Проверка владельцем»). Остальным — инструкция: отдельный Apple ID другой страны без карты, вход только в App Store («Контент и покупки»), основной аккаунт не трогаем; предупреждение о подделках «Happ» в российском App Store.
- **v2RayTun на iPhone и Mac не показываем** (на iPhone его нет нигде, отдельной Mac-версии нет); у кого стоит — работает.
- **Karing:** убираем, если и с правилом панели получает только 4 сервера из 8.
- «Россия напрямую» есть только в Happ и v2RayTun; в инструкциях остальных — честно, что весь трафик идёт через прокси (Clash Mi — можно попробовать шаблоном, см. карту).
- Если при проверке что-то не работает — убираем или переписываем (владелец).
