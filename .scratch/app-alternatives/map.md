# Альтернативные приложения для клиентов

Карта (wayfinder:map). Задачи — в `issues/`, открытые там и ищем.

## Destination

Выбраны и проверены с нашей подпиской до 4 приложений на каждое устройство (iPhone/iPad, Android, Windows, macOS, Linux), включая Happ и v2RayTun; записано, что поменять на сайте, странице подписки и в инструкциях бота. Сами правки сайта и бота — отдельные задачи разработки, не эта карта.

## Notes

- Владелец пишет по-русски; объяснять просто, термины пояснять (см. память «plain-language-explanations»). Термин «Приложение» — в `GLOSSARY.md`; не путать с «клиентом» (человек).
- 4 приложения на устройство — желательно; если хороших меньше, берём сколько есть (владелец, 2026-11-09).
- **Обязательно:** бесплатное (реклама и платный «премиум» допустимы, если подписка и наши протоколы работают без оплаты); понимает все наши подключения — VLESS Reality (tcp+vision, xhttp, gRPC) и обход через Cloudflare (ws и xhttp по TLS); добавляет подписку по ссылке / кнопкой; ставится русским пользователем без танцев (российский App Store / Google Play или официальный файл); обновлялось за последние ~3 месяца.
- **Желательно:** русский интерфейс, «Россия напрямую» из подписки, открытый код. При прочих равных — то, чем клиенты уже пользуются (Hiddify ~4, Streisand ~2, v2rayNG/v2rayN/V2Guard по 1–2; задача 37 в `tsproxy-bot`).
- «Россия напрямую» для новых приложений: если приложение умеет получать правила из подписки — настраиваем как для Happ/v2RayTun; если нет — честно пишем в инструкции. Любое изменение на сервере — только после «ок» владельца.
- **Проверка:** Android, Windows, Linux — агент сам в эмуляторах/виртуальных машинах, которые ставит владелец. iPhone/iPad (симулятор без App Store) и, если виртуалка Windows ARM подводит, Windows — владелец на своих устройствах по списку шагов агента.
- Итог карты питает: список приложений на странице подписки (`vpn-bot-rework/issues/24`), инструкции сайта (`tsproxy-site/issues/08`, `config/site.yaml` → `apps`), инструкции бота.
- Исследования: навык `research`, высокодоверенные источники (официальные сайты, GitHub-релизы, страницы магазинов).
