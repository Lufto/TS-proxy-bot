# Клиент сам перевыпускает ссылку подписки

Type: task
Status: ready-for-agent
Blocked by: 08, 18

## Что сделать

Решение владельца 2026-10-25 (ideas.md №13). «🗑 Удалить устройство» только освобождает место в списке: устройство, уже получившее настройки, продолжает работать. Выгнать чужое устройство можно только перевыпуском ссылки.

- В «👤 Мой профиль» и в «📱 Мои устройства» — кнопка «🔄 Перевыпустить ссылку».
- По нажатию — предупреждение: «Старая ссылка перестанет работать на всех устройствах — подписку нужно будет добавить заново. Перевыпустить?» и кнопки «✅ Да, перевыпустить» / «Отмена».
- После «Да» — `revoke_subscription` в Remnawave, событие в журнале, экран с новой ссылкой (как «🚀 Подключиться»: «Открыть страницу подключения», «📋 Скопировать ссылку»).
- **Не чаще раза в сутки** на клиента. Без изменения схемы базы: время последнего перевыпуска — по журналу событий. Раньше суток — экран «Перевыпустить можно будет {когда}» с датой по Москве.
- Только своя ссылка: клиент — `from_user.id`, кнопка ничего не несёт, кроме действия. Двойное «Да» (гонка) не перевыпускает дважды.
- Нет аккаунта — экран «подписки нет» (как в профиле). Панель не ответила — как в «Подключиться».

## Готово, когда

- Тесты: перевыпуск даёт новую ссылку; второй раз за сутки — отказ с датой; через сутки — снова можно; двойное «Да» — один перевыпуск.
