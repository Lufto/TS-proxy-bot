# 04: Права администратора, вебхуки и служебные адреса

## Находки

**Права администратора.** Перечислены все роутеры бота (`bot/*.py`). Каждая команда и кнопка админки (`/client`, `/give`, `/stats`, `/announce`, `/proof`, `/broadcast`, `/banner`, `/trials`, `/outages`, `/transfer`, кнопки карточки клиента, возвратов, компенсации, рассылки, баннера, пробных, переноса, кнопки темы обращения и быстрые ответы, ответы администратора в теме) стоит за `AdminFilter`: отправитель из `ADMIN_IDS` **и** чат — группа администраторов. Сообщения от имени канала или анонимного администратора не проходят. Клиентские экраны отвечают только в личном чате; из чужих групп и каналов бот выходит.

Было: отдельные тесты «чужой не может» у 9 частей админки (в т.ч. `/announce`, все кнопки темы обращения — и для чужого в группе, и для администратора в личке). **Добавлено** `bot/tests/bot/test_admin_access.py`: `/client`, `/give`, `/banner`, `/trials` × (обычный клиент в группе администраторов; администратор в личном чате) — в группу ничего не уходит, журнал пуст, аккаунт в панели не создаётся; плюс контроль «администратор в группе ответ получает», чтобы тест не проходил впустую. Без отдельного теста только `/stats` — он лишь показывает цифры.

**Вебхуки.** Telegram — секрет в заголовке, сравнение без утечки по времени, без секрета 403 (есть тест `test_webhook.py`). Remnawave — подпись HMAC-SHA256 тела, неверная подпись 403 и склеенная тревога, тело больше лимита 413 (14 тестов `test_remnawave_webhook.py`). Platega — задача 01.

**Служебные адреса** (проверено на `https://bot.ts-proxy.com`, только GET): `/health` → `ok`; `/status` → `{"banner":"none"}`, `Access-Control-Allow-Origin: *`, без кеша; `/docs`, `/redoc`, `/openapi.json`, `/.env`, `/.git/config` → 404 (страницы документации FastAPI выключены). Версий, внутренних адресов и данных клиентов не отдают.

**Поддержка:** клиент видит только ответы администратора; внутреннее (карточка клиента, кнопки) — только в теме группы администраторов.

### Для задачи 10

- `POST /telegram/webhook` без заголовка `X-Telegram-Bot-Api-Secret-Token` → 403; с неверным → 403.
- `POST /remnawave/webhook` без подписи → 403 (+ одна тревога); с неверной подписью → 403; тело 2 МБ → 413.
- `GET /health`, `GET /status` → только `ok` / `{"banner":…}`.
- `GET /docs`, `/redoc`, `/openapi.json`, `/.env`, `/.git/config`, `/admin` → 404.
