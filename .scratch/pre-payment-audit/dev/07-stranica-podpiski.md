## Находки

**Подбор адреса.** Страница находит подписку по короткому коду из адреса `sub.ts-proxy.com/<код>` (его выдаёт Remnawave; случайный, подобрать перебором нереально). На выдуманный код сервер страницы молча обрывает соединение — снаружи это выглядит как 502 Cloudflare, без отличия «нет такой подписки» от сбоя. Проверено 2026-11-10: 9 запросов с выдуманными кодами (`AAAA…`, `abc`, `<script>`, `../api/users`, с видом Happ) — все оборваны; за сутки 15 обычных ответов 200 настоящим клиентам; контейнер `remnawave-subscription-page` здоров (только чтение по SSH: `docker ps`, `docker logs`).

**Вывод данных** (`src/main.ts`, `src/panel.ts` публичного репозитория). HTML собирается строками, но всё, что приходит из панели, безопасно: имя аккаунта и ссылка — через `esc()`; дни, трафик, дата — через `Number`/`Date` (мусор станет `NaN`, не HTML); QR — SVG из ссылки библиотекой `uqr`; остальное — постоянные тексты и ссылки из `config.ts`. Подставить чужой HTML или скрипт через данные подписки нельзя (имена ручных аккаунтов панели — тоже через `esc()`).

**Публичный репозиторий** `Lufto/page-subscription` — проверен в задаче 05: `gitleaks` чисто, IP, токенов и заметок нет. Ссылка «Исходный код» (AGPL) — в подвале каждой страницы, ведёт на этот репозиторий.
