# 02: Звёзды, возвраты, спор через банк, перенос подписки

**What to build:** владелец знает, что в оплате звёздами нельзя подменить тариф или сумму, возврат нельзя провести дважды и он забирает ровно оплаченные дни, а спор через банк и перенос подписки не дают лишних дней.

**Blocked by:** None (can start immediately)

**Status:** done (2026-11-10)

Общие правила — в `../spec.md` и заметках `../map.md`: 🔴 лазейку закрываем сразу с автотестом (место проверки «бот целиком без сети»), 🟠/🟡 только записываем; деньги и прокси-аккаунты ломаем только на стенде; на серверы ничего без «ок» владельца.

- [x] Звёзды: проверка счёта перед оплатой и после неё — подмена тарифа или суммы, повтор успешной оплаты, оплата старого счёта
- [x] «↩️ Вернуть»: двойное нажатие, возврат уже возвращённого, возврат после переноса; списываются ровно дни этой оплаты
- [x] Спор через банк и перенос подписки не дают лишних дней ни одной из сторон
- [x] 🔴 закрыты с тестом, набор тестов зелёный, находки под «## Находки»

## Находки

Разобрано по коду (`services/stars.py`, `domain/stars.py`, `services/refunds.py`, `services/payment_status.py`, `services/transfer.py`) и имеющимся автотестам (70 по этим частям: подмена суммы и чужой счёт звёздами, повтор оплаты, оплата старого счёта, двойное нажатие «↩️ Вернуть», два одновременных нажатия, возврат после переноса, возврат оспоренной оплаты, повтор колбэка спора, «наш возврат» не считается спором). 🔴 в коде нет, новых тестов не понадобилось.

Почему лазеек нет: звёзды — перед оплатой сверяются заказ этого клиента, срок счёта, сумма и валюта; номер платежа Telegram пишется в заказ одним `UPDATE … WHERE номера нет`; не подошедшие звёзды возвращаются. Возврат начинается одним `UPDATE «доступ выдан» → «возвращён»`, снимаются ровно дни этой оплаты (`paid_duration`), окно — 14 дней (с 2026-11-10).
