# Общий конфиг сайта и бота

Type: grilling
Status: closed
Blocked by: 11

## Question

Что вынести в один общий файл, который читают и бот, и сайт? Кандидаты: тарифы и цены (сейчас `content/tariffs.yaml`), имя бота, почта поддержки, ссылки на приложения в сторах, адрес проверки бота. Решить: состав, формат, место в репозитории, как сайт читает его при сборке и что бот меняет у себя.

## Answer

2026-11-09, по умолчанию (владелец: «запускай, если нет вопросов»).

- `config/tariffs.yaml` — как есть, бот уже читает его оттуда.
- `config/site.yaml` — новое: имя бота, почта поддержки, адрес состояния бота для плашки, ссылки на приложения (Happ и v2RayTun по платформам).
- Сайт читает оба файла при сборке: скрипт пишет `web/src/generated-config.ts`, страницы берут данные оттуда. Руками в коде сайта ничего не вписано.
- Бот читает только тарифы; имя бота у него остаётся в `.env` (`BOT_USERNAME`), его нужно держать одинаковым с `site.yaml`.
- Скидка на сайте считается той же формулой, что в боте (`domain/money.py`): целые месяцы = дни // 30, проценты вниз.
