# Карта: новый сайт ts-proxy.com

Labels: wayfinder:map

## Destination

Новый сайт на Next выложен на `ts-proxy.com` и заменил старый `site/`. У сайта свой UI-кит, логотип и фавикон, переработаны тексты, есть русская и английская версии. Сайт показывает плашку о неполадках. Запасной статической страницы нет: обычный Next.

## Notes

- Задачи разработки: [dev/](dev/), 01–16, ссылаются на задачи-решения карты как на блокеры. Пока сайт не готов, он живёт только локально; на сервер — последней задачей.
- Спецификация: [spec.md](spec.md) (`ready-for-agent`, 2026-11-08). Обновлять по мере закрытия задач.

- **Сборка входит в карту** (владелец, 2026-11-08). Задачи этой карты не только решают, но и делают: заготовка, кит, страницы, выкатка.
- Стек: Next 16, React 19, TS, Tailwind 4 из шаблона `~/Documents/create-app/assets/templates/nextjs-ts-tailwind`. Берём структуру и настройки шаблона: eslint, иконки-спрайты, данные в `apiStatic`. Закрытые пакеты `@idem.agency/*` оставляем: у владельца есть доступ.
- Репозиторий `vpn bot` делится на две части (владелец, 2026-11-08): корень общий (`.scratch/`, `docs/`, `ops/`, `prototypes/`, общий конфиг `shared/`, `GLOSSARY.md`), бот в `bot/`, сайт в `web/`. Старый `site/` удаляем после переключения домена. **Первой делаем задачу разработки «Бот переезжает в bot/, тарифы в shared/».**
- Страницы: главная-промо (с тарифами), инструкции (общая и по устройствам), соглашение, политика, 404. **Отдельной страницы поддержки нет**: кнопки ведут в бота. Почта `support@ts-proxy.com` остаётся в документах.
- Языки: русский по умолчанию без приставки в адресе (`/terms`), английский — `/en/...`. Адреса `/terms` и `/privacy` не меняем: на них ссылается бот. Документы переводим полностью, в английской версии оговорка «при расхождении действует русский текст».
- Сайт работает службой на основном сервере. Схему и порты выбирает агент (на 443 стоит нода, вероятно, через туннель Cloudflare `pereezd`). Работы на сервере — только после «ок» владельца на каждое действие.
- Стиль: тёмный, сдержанный, но захватывающий, с выразительной типографикой; смесь «строгий технологичный», «спокойный как банк», «смелая крупная типографика». UI-кит: кнопки, ссылки, палитра, шрифты и заголовки, пример блока, логотип, фавикон. Делаем в вёрстке, без Figma (владелец, 2026-11-08). Кит разворачиваем на корне сайта, потом корень заменяем страницами, а кит остаётся.
- Тексты: **только «прокси», слово «VPN» не используем**. Не обещаем доступ к заблокированному и обход блокировок. «Без логов» не пишем, пока не проверено. Черновик: `.scratch/vpn-bot-rework/drafts/pozitsionirovanie.md`, правила — задача 27 в `.scratch/tsproxy-bot`.
- Счётчиков и аналитики нет. Поисковикам сайт открыт, превью ссылок в Telegram нужно.
- Для решений вызывать скилы `grilling` и `domain-modeling`, для кита — `prototype`. Объяснять просто, по-русски.
