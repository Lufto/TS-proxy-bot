# Проверка владельцем на тестовом боте

Type: task
Status: open

## Question

Владелец проходит все изменённые экраны на тестовом боте на Mac по списку от агента (что нажать, что должно получиться) и говорит «ок» или что поправить. Правки — новыми задачами карты. 

## Как проверить (для владельца, @ts_proxybot, ветка `ui/telegram-ui`)

Подготовка: `git switch ui/telegram-ui`, `cd bot && uv sync`, запустить бота как обычно; профиль — `uv run python scripts/set_bot_profile.py` (если старый аватар остался — добавить `--replace-avatar`); в BotFather загрузить `bot/content/images/description.png` (шаги — `bot/docs/areas/server.md`, «Профиль бота в Telegram»).

1. **Профиль.** Аватар — оранжевый знак; описание в пустом чате — картинка «Одна подписка — все устройства» и текст «Что умеет этот бот?»; ts-proxy.com — ссылкой.
2. **Главное меню (`/start`).** Фото с индикатором по статусу (зелёный / жёлтый / красный / серый «Добро пожаловать» для нового); строка статуса; кнопки без смайликов, «Подключиться» зелёная. Без «Соглашения» и «Конфиденциальности».
3. **Живое меню.** Нажмите несколько кнопок: каждый экран приходит новым сообщением, прошлое исчезает, чат поднимается в списке. Повторный `/start` — в чате одно меню.
4. **«О сервисе».** Фото с тремя цифрами, короткий текст, кнопки «Сайт», «Соглашение», «Конфиденциальность», «В меню».
5. **Инструкции.** Короткие, со ссылкой на вашу страницу подключения и на сайт; без запасных приложений.
6. **Поддержка.** Напишите вопрос → «Спасибо! Обращение принято…» без номера, с «В меню». Ответьте из темы группы → под ответом «В меню»; нажмите — открылось меню, ответ остался текстом без кнопки.
7. **Перевыпуск ссылки.** После перевыпуска кнопка серая сутки, на экране — когда снова можно.
8. **«Печатает…»** — при «Подключиться», профиле, устройствах, оплате.
9. **Даты** — по вашим часам (на телефоне и на Mac), не «МСК». Если длинно — сказать (todo п. 38).
10. **Сутки простоя** — проверить нельзя быстро; покрыто тестами. По желанию: оставить экран профиля на сутки и нажать «Назад» — должно открыться главное меню.

Что не понравилось — пишите по номеру пункта, каждая правка станет задачей карты.
