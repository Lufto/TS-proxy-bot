# Выбрать идеи из подборки

Type: grilling
Status: resolved
Blocked by: 02

## Question

Какие идеи из подборки берём в эту карту, а какие — нет? Каждая взятая идея становится задачей-исполнением; отброшенные — в «Out of scope» карты с причиной.

Первым вопросом — подтвердить или пересмотреть «живое меню» (новое сообщение на каждое нажатие): Telegram советует править сообщение. Вариант-компромисс: править внутри меню, новое сообщение — только после паузы (например, 10+ минут без нажатий).

## Answer

Решено с владельцем 2026-11-18.

- **Живое меню — вариант А** (новое сообщение на каждое нажатие) подтверждён, несмотря на совет Telegram править сообщение; компромисс с паузой отклонён.
- **Берём:** цветная главная кнопка (зелёная «Подключиться», красные — опасные действия); кнопки без смайликов (смайлики только со смыслом: ✅/⛔ в статусе, 🎁 в заголовке), цитаты кнопок в текстах бота и сайта обновить; статус подписки в главном меню; серая неактивная кнопка вместо экрана-отказа; короткие ответы всплывашкой; «печатает…» при ожидании панели и платёжки; время по часам клиента (`<tg-time>`, запасной текст — МСК; правило «даты по Москве» меняется); убрать повторы «не пересылайте ссылку»; «О боте» с сайтом — в профиле бота.
- **Запасные приложения** из инструкций в боте убираем совсем — «подробнее на сайте».
- **Не берём:** закреплённая карточка подписки, инструкция кнопками вместо ссылок, «Поделиться с другом», конфетти, ссылки `?start=<экран>`, иконки-эмодзи на кнопках (Premium), Mini App, подарки и бонусы.

Исполнение — задачи 13–29.
