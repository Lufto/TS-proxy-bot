# 17: Личная страница подключения в инструкциях

Type: task
Status: open
Blocked by: 16

**What to build:** во фразе инструкции «откройте вашу страницу подключения» — личная ссылка подписки клиента. Нет прокси-аккаунта или панель не ответила — «нажмите „Подключиться“», ссылка на сайт остаётся, ошибки нет. [Спека](../spec.md#инструкции).

- [ ] Клиент с прокси-аккаунтом видит ссылку на свою страницу
- [ ] Без прокси-аккаунта — фраза про «Подключиться»
- [ ] Панель не ответила — та же фраза, тревога не уходит
- [ ] Тесты на три случая на уровне бота целиком
