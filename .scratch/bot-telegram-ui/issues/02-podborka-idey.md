# Подборка удачных решений интерфейса из других ботов

Type: research
Status: resolved

## Question

Какие решения по интерфейсу в известных Telegram-ботах (любых: магазины, сервисы, банки, прокси) стоит взять в TS Proxy? Для каждой идеи: что это, у кого подсмотрено (ссылка), какую боль клиента решает, сколько работы (мало/средне/много), не спорит ли со [спекой](../spec.md). Отдельно отметить, что из нашего бота сейчас хуже всего по сравнению с ними (посмотреть экраны в `bot/content/client/`). 10–20 идей, отсортировать по пользе на работу.

## Answer

18 идей — [research/podborka-idey.md](../research/podborka-idey.md). Источники: документация Telegram, README открытых ботов на Remnawave (Bedolaga, remnawave-telegram-shop), UX-гайд Dodo; живые экраны чужих ботов не открывались.

- **Против решения «живое меню»:** Telegram на странице возможностей ботов советует править сообщение — «быстрее и плавнее», чем новое + удаление. Вынесено на выбор владельцу в задачу 03.
- Дешёвые и полезные: цветная главная кнопка, запасные приложения под раскрывающийся абзац, короткие ответы всплывашкой, «печатает…» при ожидании, ссылки `?start=<экран>`, даты по часам клиента, серая неактивная кнопка вместо экрана-отказа, статус подписки в главном меню.
- Спорят со спекой: инструкция кнопками вместо ссылок в тексте (11), закреплённая карточка подписки (15).
- Вне этой работы: Mini App (17), подарки и бонусы (18) — логика оплаты.
- Хуже всего сейчас: инструкции — стена текста (~1300 знаков), не видно статуса подписки в меню, 5–6 нажатий до подключения, «не пересылайте ссылку» на четырёх экранах, время только по Москве.
