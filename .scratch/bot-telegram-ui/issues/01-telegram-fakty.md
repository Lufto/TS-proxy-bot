# Что Telegram позволяет боту

Type: research
Status: resolved

## Question

Проверить по документации Bot API (core.telegram.org/bots/api, /bots/features) факты, от которых зависят задачи карты:

1. `deleteMessage` / `deleteMessages`: срок 48 часов для своих сообщений в личном чате; что возвращает Telegram, если сообщение старше или уже удалено (текст ошибки).
2. `editMessageReplyMarkup` (убрать кнопки): есть ли срок для старых сообщений.
3. Чат поднимается в списке только от нового сообщения, а правка его не поднимает — подтвердить.
4. Сообщение с картинкой: предел подписи (1024?), можно ли править подпись и кнопки, можно ли превратить текстовое сообщение в фото правкой.
5. Профиль бота: что бот задаёт сам через API (`setMyDescription`, `setMyShortDescription`, фото профиля?), а что только через BotFather (картинка описания, аватар).
6. Есть ли новые возможности оформления (цветные кнопки, кнопки-иконки, ссылки-превью и т. п.), полезные для экранов бота.

Ответ — коротким списком с ссылками на источник; версия Bot API, которой проверено.

## Answer

Подробно — [research/telegram-fakty.md](../research/telegram-fakty.md) (Bot API 10.4, 9 ноября 2026).

- Удалить своё сообщение можно только первые 48 часов; старше — `message can't be deleted for everyone`, уже удалено — `message to delete not found`. `deleteMessages` пакетом падает целиком из-за одного старого — удалять живое меню по одному.
- Убрать кнопки (`editMessageReplyMarkup`) можно без срока; повтор даёт `message is not modified` — не ошибка.
- Чат поднимает только новое сообщение; правка не поднимает, удаление последнего не опускает.
- Подпись к фото — до 1024 символов; подпись и кнопки правятся; текст можно превратить в фото, фото в текст — нет.
- Описание, короткое описание, имя и **аватар** (`setMyProfilePhoto`, с 9.4) бот ставит сам; картинку описания в пустом чате — только BotFather.
- Новое оформление: цветные кнопки (`style`), иконки-эмодзи на кнопках (нужен Premium владельца или имя с Fragment), неактивные кнопки, кнопка «скопировать текст», настройки превью ссылок, сообщения с заголовками/списками/таблицами (поддержку в aiogram не проверяли).
