# Картинки: аватар, описание бота, главное меню, «О сервисе»

Type: prototype
Status: resolved
Blocked by: 01

## Question

Как выглядят четыре картинки бота? Стиль сайта, основа — `site/assets/logo.svg`. Агент делает 2–3 варианта каждой в нужных Telegram размерах (из задачи 01), владелец выбирает. Итог — готовые файлы в репозитории и список, какая куда идёт.

## Answer

Решено с владельцем 2026-11-18. Стиль A «как сайт» (чёрный, оранжевое свечение, Unbounded, логотип сайта). Прототип — ветка `prototype/bot-images` (не сливать). Файлы — `bot/content/images/`:

- `avatar.png` 640×640 — знак на чёрном.
- `description.png` 640×360 (картинка описания, BotFather) — «Одна подписка — все устройства», над ним «iPhone · Android · Windows · macOS · Linux».
- `menu-active.png`, `menu-grace.png`, `menu-expired.png`, `menu-new.png` 1280×560 (главное меню) — индикатор цветом статуса подписки: зелёный «на связи» / жёлтый «доступ сохранён» / красный «нет доступа» — «С возвращением»; серый «не подключено» — «Добро пожаловать» (нет прокси-аккаунта или панель не ответила).
- `about.png` 1280×560 («О сервисе») — три цифры: 3 устройства, 5 платформ, 2 мин.
- Подпись под меню — только строка статуса и «Выберите, что нужно:» (строку «TS Proxy — прокси-сервис…» убрать, она на картинке). Подпись «О сервисе»: «Шифруем ваш трафик, скрываем IP-адрес и защищаем данные в публичных Wi-Fi сетях. До 3 устройств на одной подписке.»
- Описание бота («Что умеет этот бот?», ts-proxy.com — ссылкой):

  Прокси с шифрованием трафика — для iPhone, Android, Windows, macOS и Linux.

  — шифруем трафик и скрываем IP-адрес, даже в открытом Wi‑Fi
  — подключение за пару минут, без настроек вручную
  — до 3 устройств на одной подписке
  — поддержка отвечает прямо здесь, в чате

  Нажмите «Запустить», чтобы начать. Подробнее — ts-proxy.com
