# 25: Уведомления и ответы поддержки теряют кнопки, но не удаляются

Type: task
Status: open
Blocked by: 14, 24

**What to build:** сообщения с сохраняемым текстом (уведомления, ответы поддержки, «Обращение принято», сообщения об оплате) при появлении нового живого меню теряют только кнопки. Решить и записать, какие фоновые уведомления становятся живым меню. [Спека](../spec.md#живое-меню).

- [ ] Уведомление с кнопками → новое меню → кнопки уведомления сняты, текст на месте
- [ ] То же для ответа поддержки и «Обращение принято»
- [ ] Переписка клиента и чеки не трогаются
- [ ] Список фоновых уведомлений и их поведение — в docstring и спеке
- [ ] Тесты на уровне бота целиком

Из задачи 23 (2026-11-18): сохраняемый текст уже различается без памяти — `Screen.kept()` / `keeps_text`, метка `~` в данных кнопок, `KeptTextMiddleware`; при нажатии на такое сообщение гаснут только кнопки. Осталось: (1) «Обращение принято» и ответы поддержки с «В меню» — пометить, если задача 14 не сделала; (2) сообщения со ссылкой, которые бот присылает сам, когда панель ожила (после «Пробный» и «Подключиться»), — решить, сохраняемые ли; (3) уведомления, отправленные до выкатки, метки не имеют и при нажатии удалятся — принять или обойти.
