# 24: Живое меню — `/start` и сообщения бота убирают прошлое меню

Type: task
Status: resolved
Blocked by: 23

**What to build:** бот помнит последнее живое меню клиента в памяти (база не меняется); `/start` и любой новый экран, присланный не по нажатию, убирают прошлое. После перезапуска допустимо одно старое меню — уберётся при нажатии на нём. [Спека](../spec.md#живое-меню).

- [ ] После `/start` в чате одно меню
- [ ] Перезапуск (новый контекст бота): нажатие на старом меню убирает его
- [ ] Тесты на уровне бота целиком

## Answer

Сделано 2026-11-18, слито в `ui/telegram-ui` (bc04241). `ClientDelivery` помнит последнее живое меню клиента в памяти; `/start`, команды и уведомления (`send()`) убирают прошлое меню, сохраняемый текст теряет только кнопки; после перезапуска старое меню уберётся при нажатии.
