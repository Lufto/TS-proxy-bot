# 13: Кнопки без смайликов и с цветом

Type: task
Status: open
Blocked by: —

**What to build:** все кнопки бота клиенту — без смайликов; главная кнопка экрана зелёная («Подключиться»), опасные действия красные («Удалить устройство», «Перевыпустить ссылку», «Вернуть деньги»). Тексты бота и страницы сайта, где кнопка процитирована («нажмите „🚀 Подключиться“»), говорят новыми названиями. Смайлики остаются только там, где несут смысл (✅/⛔ в статусе, 🎁 в заголовке). [Спека](../spec.md#кнопки).

- [ ] Ни у одной кнопки клиента нет смайлика в начале
- [ ] «Подключиться» — зелёная, опасные действия — красные (Bot API `style`)
- [ ] В `bot/content/` и в `site/` нет цитат кнопок со старыми названиями
- [ ] Тест текстов проходит; тест меню проверяет цвет главной кнопки
- [ ] Кнопки админки не трогаем
