# Формат тревоги

Type: grilling
Status: resolved
Blocked by: 01, 02

## Question

Как именно устроена тревога из четырёх частей: «что случилось», «где заметили», «чем грозит», «куда смотреть»?

Что решить:
- откуда берётся «где заметили»: пишется в тексте рядом с каждой тревогой или бот определяет место в коде сам (например, по трассировке ошибки, то есть цепочке вызовов функций);
- как склеивать повторы, если причина разная (сначала 502, потом «не дождались ответа»): одна тревога или разные, и что писать в сводке повторов;
- что показывать для «Ошибки в боте», где сейчас есть только тип ошибки: место в коде, сообщение ошибки, действие клиента;
- предел длины (Telegram — 4096 символов) и маскировка секретов в подробностях;
- 2–3 тревоги, переписанные начисто как образец для всех остальных.
