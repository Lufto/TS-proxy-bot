# 05: Тревоги оплат

**What to build:** Ошибки Platega несут вид сбоя и подробности. В новом формате приходят тревоги: платёжка не отвечает / отказала создать платёж, проверка оплат недоступна / отказала (ключи), поддельное уведомление, оплата не записалась, платёж не засчитан, сверка оплат (расхождения / недоступна / отказ), спор через банк, сумма не совпала, оплата выключена. Номер заказа, платёж и клиент сохраняются. Причины — из `../research/prichiny-sboev.md` (раздел Platega).
