# 07: Сводка повторов по причинам

**What to build:** Если за окно склейки одна тревога повторялась с разными «что случилось», сводка показывает счёт по каждой причине («HTTP 502 — 14, не дождались ответа — 3»). Окно, ключи и правила склейки не меняются; сводка без кнопки, как сейчас.

**Blocked by:** 02

**Status:** resolved

- [x] Тест: одна причина — сводка как раньше по смыслу.
- [x] Сводка не превышает предел Telegram при многих разных причинах.
