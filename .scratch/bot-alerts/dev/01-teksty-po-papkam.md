# 01: Тексты по папкам client/, admin/, alerts/

**What to build:** Тексты бота лежат в трёх папках (`client/`, `admin/`, `alerts/`), внутри — по одному файлу на раздел бота. Ключи текстов прежние, бот показывает ровно те же тексты. Комментарии — одна строка: кто и когда видит текст, что подставляется. Истории «задача NN: …» убраны. Подробности — спецификация `../spec.md`, раздел «Тексты: папки и загрузка».

**Blocked by:** None (can start immediately)

**Status:** resolved

- [x] Загрузчик собирает все `.yaml` из `client/` в клиентский набор, из `admin/` и `alerts/` — в административный; остальной код не меняется.
- [x] Одинаковый ключ в двух файлах останавливает запуск; ошибка называет ключ и оба файла (тест).
- [x] Ошибка о недостающем тексте называет папку.
- [x] Каждый верхний раздел ключа целиком живёт в одном файле; в папке не больше ~15 файлов.
- [x] Значения всех текстов до и после совпадают побайтно (проверено скриптом при переезде; разница — только комментарии).
- [x] Все существующие тесты проходят без правки ожидаемых текстов.
