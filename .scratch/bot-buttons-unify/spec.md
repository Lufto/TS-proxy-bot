# Кнопки бота: одно название — одно действие

Status: ready-for-agent

## Зачем

Первый платный клиент (2026-11-20) не нашёл ссылку подписки. В сообщении «✅ Оплачено» она была только кнопкой; клиент открыл профиль, кнопки сообщения погасли, а «Подключиться» вело на ещё один экран, где нужна вторая кнопка. Владелец: «у нас много одинаковых кнопок, ведущих в разные места, нужно поработать над опытом клиента».

## Решения владельца (2026-11-20)

1. **«Подключиться» — сама ссылка.** Везде, где бот знает аккаунт и доступ есть (пробный, оплаченный, льготный), «Подключиться» — кнопка-ссылка на страницу подписки `sub.ts-proxy.com/<код>`, без промежуточного экрана. В том же ряду — «Скопировать ссылку». Ссылка ещё и в тексте сообщения, где она нужна для подключения («Оплачено», «Пробный включён», «Подключение»): кнопки сохраняемых сообщений гаснут при следующем меню.
   - Кнопки «Открыть страницу подключения» больше нет.
   - Бот не знает ссылку (нет аккаунта, панель не ответила или не успела, доступ приостановлен) — «Подключиться» работает как раньше: экран «подписки нет» / «пришлём ссылку» / «подписка закончилась».
   - Доступа нет (подписка закончилась, кончился пробный трафик) — «Подключиться» в меню не показываем: ссылка всё равно не работает, на её месте «Продлить подписку» / «Тарифы».
2. **«Тарифы» или «Продлить подписку» — по ситуации.** Была оплаченная подписка (идёт, льготный, закончилась) — «Продлить подписку»; нет подписки или пробный — «Тарифы». Обе ведут в тарифы, на одном экране никогда не стоят вместе.
3. **«Назад» и «В меню».** На экране, с которого можно вернуться на шаг, — одна кнопка «Назад» (на шаг выше). Там, где действие совершено (оплата, выдача, ответ, отказ, уведомление), — одна кнопка «В меню». Две кнопки «назад» на одном экране не ставим. Кнопки «В профиль», «К тарифам», «Другое устройство», «К частым вопросам» заменяет «Назад».

## Куда ведёт «Назад»

| Экран | «Назад» |
|---|---|
| Тарифы, Мой профиль, Инструкции, Поддержка, О сервисе, «Подключение» | главное меню |
| Экран тарифа (СБП / Stars) | Тарифы |
| Ссылка на оплату СБП, «счёт в звёздах ниже», счёт в звёздах | экран этого тарифа |
| Мои устройства | Мой профиль |
| Инструкция для устройства | Инструкции |
| Ответ на частый вопрос | Поддержка |
| Перевыпуск ссылки — предупреждение | остаётся «Отмена» (подтверждение, не переход) |

## Вне задачи

- Уведомление «пробный продлён» знает только срок, не ссылку: «Подключиться» в нём остаётся кнопкой экрана подключения (на экране — ссылка). Записано в `bot/docs/todo.md`.
- Админка не меняется.
