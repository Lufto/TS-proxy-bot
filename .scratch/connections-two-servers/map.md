# Карта: два сервера, на каждом рабочие подключения

Label: wayfinder:map
Начата: 2026-11-20

## Destination

На каждом из двух серверов (Германия, Германия 2) у всех клиентов есть минимум одно **прямое** подключение (Reality) и одно **доменное** (через Cloudflare), оба проверены из России. Нерабочие подключения скрыты (выключены в панели, не удалены).

## Notes

- Карта включает выполнение, не только решения. На серверах агент может читать и тестировать без спроса; любое изменение настроек — только после «ок» владельца на это действие. Исключение (владелец, 2026-11-20): подключения, которые проверка показала нерабочими из России, агент выключает сам.
- «Нерабочее» = не работает из России. Скрываем выключением хоста в панели, не удаляем.
- Термины — `GLOSSARY.md`: сервер, подключение, доменное подключение.
- Проверка из России: check-host.net (точки в РФ) и владелец с телефона. Mac агента ходит через наш прокси (выход 130.78.12.241) — проверки с него о блокировках ничего не говорят.
- Состояние на 2026-11-20 (разведка): все 8 подключений включены; Германия 2 уже есть у всех (её инбаунды в `Default-Squad`, 40 клиентов), но онлайн на ней 0, на основном 8. Подключения 1–4 Германии и оба Германии 2 — Reality; маскировка основного — мёртвый `nani.alttux.site` (todo п. 37), Германии 2 — `www.pinterest.com`. Оба сервера в одной подсети 130.78.12.x одного хостера.
- Владелец (2026-11-20): попросит у хостера сменить IP основного. Маскировка — своя сайт-заглушка на каждом сервере (self-steal).
- Адрес прямых подключений не держим под `ts-proxy.com`: `node1.ts-proxy.com` (серое облако) открывает IP, за которым стоит `api.ts-proxy.com`, и связывает сервер с брендом. Прямые подключения — по нейтральному поддомену заглушки этого сервера (он же имя маскировки Reality); `node1` к новому IP не привязываем.
- Прошлая разведка: `.scratch/archive/tsproxy-bot/issues/37-podklyucheniya-i-maskirovka.md`.

## Out of scope

- Третий сервер у другого хостера — следующая карта, после того как два нынешних заработают (владелец, 2026-11-20).
- Российский VPS как постоянная точка проверки и мониторинга.
- MTProto-прокси `mtg` на Германии 2.
