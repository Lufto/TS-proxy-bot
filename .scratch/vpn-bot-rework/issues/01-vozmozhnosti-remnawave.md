# Возможности Remnawave

Type: research
Status: resolved

## Question

Что панель Remnawave и Python SDK `remnawave` умеют для наших тарифов:
- лимит устройств (HWID): как включается, задаётся ли для каждого VPN-аккаунта, что видит клиент при превышении;
- что показывает ссылка подписки или страница подписки (срок, трафик, устройства), можно ли её настроить;
- есть ли ограничение скорости для отдельного аккаунта (в оффере «до 1 Гбит/с»);
- как правильно сделать пробный период (статус, срок, лимит трафика);
- какие поля и форматы возвращает SDK (snake_case или camelCase, enum статусов) в актуальной версии, какие ошибки бросает.

Результат — в `.scratch/vpn-bot-rework/research/remnawave.md`.

## Answer

Подробности и источники: `.scratch/vpn-bot-rework/research/remnawave.md`.

- **Несовместимость:** пакет `remnawave` (2.8.0), который использует набросок, заархивирован и с панелью 3.x не работает: в 3.x нет `uuid`, пользователя определяют числовым `id`, поиск по `telegram_id` переехал. Актуальный пакет — `remnawave-api` (модуль тоже называется `remnawave`) под версию нашей панели. Версию панели узнаём в задаче 03.
- **Устройства:** HWID-лимит включается в настройках панели, а для каждого VPN-аккаунта задаётся полем `hwidDeviceLimit` (0 — без лимита, null — общий fallback, N — N устройств). Лимит проверяется при обновлении подписки. Устройства можно смотреть и удалять через API.
- **Ссылка подписки** отдаёт приложению срок и трафик. Отдельная страница подписки (`remnawave/subscription-page`) показывает срок, трафик и статус (устройств на ней нет) и настраивается в панели: приложения по платформам, брендинг, языки.
- **Скорость** для отдельного пользователя ограничить нельзя. «До 1 Гбит/с» — это свойство канала сервера. Ограничить можно только объём трафика.
- **Пробный период** собирается из обычных полей: срок now+24ч, при желании лимит трафика, `hwidDeviceLimit`, тег `TRIAL`. Признак «пробный уже выдан» храним в своей базе.
- Для продления есть готовое действие `extend {days}`. Статусы: ACTIVE, DISABLED, LIMITED (трафик исчерпан, доступа нет), EXPIRED. Ошибки различаются: `NotFoundError`, `UnauthorizedError`, сетевые (`ApiError` с `code=NETWORK_ERROR`).
- **Вебхуки Remnawave** (HMAC-SHA256): `user.expired`, `user.expiration` (напоминания по расписанию), `user.limited`, `user_hwid_devices.added` и другие. Включаются в `.env` панели, а принимать их боту нужно на HTTPS-адресе.
