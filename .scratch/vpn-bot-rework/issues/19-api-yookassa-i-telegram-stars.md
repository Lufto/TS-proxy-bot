# API ЮKassa и Telegram Stars

Type: research
Status: resolved

## Question

Факты, на которых строится модуль оплаты:

**ЮKassa (API v3):**
- создание платежа для бота: `POST /v3/payments`, подтверждение redirect, ключ идемпотентности, `metadata` (номер нашего заказа), `capture`, способы оплаты СБП и карты, `return_url` (можно ли сразу в Telegram-бота);
- сколько живёт неоплаченный платёж (`pending`), можно ли переиспользовать ссылку, отменяется ли он сам;
- уведомления (HTTP notifications): события, формат, **как проверять подлинность** (список IP ЮKassa, перезапрос `GET /v3/payments/{id}`), повторы при не-200;
- особенности для **самозанятых**: нужен ли объект `receipt`, как чеки попадают в «Мой налог», ограничения API для НПД (например, автоплатежи, возвраты);
- возвраты (`POST /v3/refunds`), автоплатежи (сохранение способа оплаты) — что доступно самозанятому;
- тестовый магазин, тестовые карты и СБП;
- официальный Python SDK `yookassa` — актуальность, async, качество; или свой тонкий клиент на `httpx`.

**Telegram Stars:**
- как бот продаёт цифровую услугу за Stars (`sendInvoice` с валютой `XTR`, `pre_checkout_query`, `successful_payment`), подписки (`createInvoiceLink` с `subscription_period`), возвраты (`refundStarPayment`);
- курс Stars к рублю для покупателя и для продавца, комиссии, сколько реально получает продавец;
- **как выводить деньги** (Fragment, TON, минимальная сумма, задержка вывода, требуется ли проверка личности), работает ли это для гражданина РФ, налоги;
- актуальность правила «цифровые товары в ботах — только за Stars» на 2026 год и как его применяют к ботам, принимающим внешнюю оплату.

Результат — в `.scratch/vpn-bot-rework/research/yookassa-api-and-stars.md`.

## Answer

Подробно и с источниками — `research/yookassa-api-and-stars.md` (2026-10-21).

- **ЮKassa:** `POST /v3/payments`, `confirmation.type=redirect`, `capture: true` явно; номер заказа — в `metadata`; ключ идемпотентности до 64 символов, живёт 24 часа (при HTTP 500 повторять с тем же ключом). Платёж по СБП и картам живёт **1 час**, затем ЮKassa сама отменяет его (`expired_on_confirmation`); пока он `pending`, ссылку можно отдавать повторно. Уведомления без подписи: проверка по IP ЮKassa (`185.71.76.0/27`, `185.71.77.0/27`, `77.75.153.0/25`, `77.75.156.11`, `77.75.156.35`, `77.75.154.128/25`, `2a02:5180::/32`) + перезапрос `GET /v3/payments/{id}`; не-200 — повторы 24 часа. Возвраты `POST /v3/refunds` (полные и частичные, до 3 лет). Автоплатежи самозанятым — по согласованию с менеджером.
- **Самозанятый:** чеки в «Мой налог» ЮKassa **не отправляет**; объект `receipt` не нужен; выплаты — в течение 2 рабочих дней; платят только физлица; по картам до 500 000 ₽/мес.
- **Тестовый магазин:** только карты и кошелёк ЮMoney, **СБП не тестируется**.
- **SDK `yookassa`** 3.13.0 — только синхронный, без таймаутов → **свой тонкий async-клиент на `httpx`**.
- **Telegram Stars:** `sendInvoice` с `XTR`; подписки через `createInvoiceLink` (период 30 дней); возвраты `refundStarPayment`, команда `/paysupport` обязательна. Продавец получает ~0,013 $ за Star (~65% от того, что платит покупатель). Вывод — только Fragment → TON-кошелёк (Gram), от 1000 Stars, ожидание до 21 дня; про проверку личности и граждан РФ первоисточники молчат. Темы в личных чатах бота не включать (комиссия 15%).
- **Правило Telegram** на 2026 год действует: цифровые услуги в ботах — только за Stars (раздел 6.2 условий для разработчиков). Санкции поэтапно: предупреждение → скрытие бота в версиях Telegram из App Store и Google Play → удаление.
