# Проверка связи с Remnawave

Type: task
Status: resolved

## Question

Рабочий ли текущий токен Remnawave и UUID Internal Squad? По сроку токен не истёк (exp ≈ 2300 год), но его могли отозвать. Нужно сделать безопасный запрос только на чтение (например, список squad'ов или поиск пользователя) и записать результат: работает ли токен, **какая версия панели** (от неё зависит выбор пакета `remnawave-api`), включён ли HWID-лимит и какой fallback, развёрнута ли страница подписки, есть ли у владельца доступ к `.env` панели, чтобы включить вебхуки.

HITL: автоматическая проверка безопасности не дала агенту запустить скрипт с токеном. Владелец либо разрешает запуск, либо запускает сам по чеклисту.

## Answer

Проверено 2026-10-20 запросами только на чтение (`/api/system/stats`, `/api/internal-squads`, `/api/system/metadata`).

- **Токен рабочий**, все запросы вернули 200.
- **Версия панели — 2.7.4** (сборка от 2026-03-30). Это старше 3.x, и даже старый пакет `remnawave` 2.8.0 официально её не поддерживает. Значит, панель нужно обновлять (задача «Обновление панели Remnawave»).
- **Squad** из наброска существует и называется `Default-Squad`. Есть ещё squad `test`.
- **Cloudflare перед панелью блокирует стандартный User-Agent Python** (ошибка 1010 `browser_signature_banned`). Со своим User-Agent запросы проходят. Боту нужно либо отправлять свой User-Agent, либо прописать в Cloudflare исключение для API-запросов с сервера бота.
- На Mac владельца Python 3.13 с python.org не видит системные сертификаты, это нужно учесть при локальном запуске (например, выполнить `Install Certificates.command`).
- HWID-лимит в панели сейчас **выключен**, у владельца есть полный доступ к панели и её `.env`.
