# Чеки самозанятого в «Мой налог»

Type: grilling
Status: open

## Question

ЮKassa не отправляет чеки самозанятого в «Мой налог», а по 422-ФЗ при оплате электронными средствами чек выдаётся в момент расчёта, и о нём сообщают покупателю. Как формируем чеки: вручную администратором (по уведомлению об оплате), автоматически через неофициальный API «Мой налог» (lknpd) из бота, или иначе. Как отдаём чек клиенту (ссылка в сообщении об оплате). Как корректируем чек при возврате. Что с доходом от Telegram Stars (выплаты в TON через Fragment) — учитывается ли он в НПД (вопрос бухгалтеру).

## Что известно (перепроверено 2026-10-21)

- ЮKassa: «Вы можете делать это вручную. В ЮKassa эта опция недоступна» (https://yookassa.ru/developers/payment-acceptance/receipts/basics) — подтверждено повторно.
- Срок: по 422-ФЗ ст. 14 при оплате электронными средствами платежа чек формируется **в момент расчёта**, то есть **на каждую продажу**, а не раз в месяц. Подтвердить у бухгалтера, что оплата через ЮKassa — именно этот случай.
- Варианты автоматизации:
  1. **Вручную** в приложении «Мой налог» по уведомлению бота — надёжно, ~20 секунд на продажу.
  2. **Неофициальный API личного кабинета** «Мой налог» (lknpd.nalog.ru, OAuth2, токен живёт 1 час) — полностью автоматически, но неофициально: может сломаться, бот хранит доступ к кабинету самозанятого.
  3. **Официальные партнёры ФНС** (соглашение об информационном обмене с ФНС) формируют чеки автоматически, но обычно только по платежам через себя (например, «Робочеки СМЗ» — для платежей Robokassa). Для платежей ЮKassa готового партнёра не найдено.
- Владелец: «пока не знаю, надо изучить» — решение отложено до консультации с бухгалтером.

## Исследование (2026-10-21)

См. `research/cheki-npd.md`: чек на каждую оплату сразу, на полную сумму (комиссия не вычитается), данные покупателя-физлица не нужны, при возврате — аннулирование с причиной «возврат средств». Бухгалтеру остаётся подтвердить срок и формулировку услуги.

### Автоматизация (2026-10-21)

Владелец: чеки вручную не делать, нужна автоматизация. Варианты:
- **А (рекомендация агента).** ЮKassa + бот сам выбивает чек через неофициальный API lknpd.nalog.ru сразу после оплаты и отправляет клиенту ссылку. Если ответа нет, бот уведомляет админа, и тот выбивает чек вручную. Ровно такая схема (ЮKassa + подписка + самозанятый) описана на https://habr.com/ru/articles/1065464/: один платёж — один чек, защита от дублей, вход по SMS, токены хранятся зашифрованными, с зарубежного сервера связь нестабильна. Плюсы: бесплатно, платёжку менять не нужно. Минусы: API неофициальный и может сломаться, бот хранит доступ к «Мой налог».
- **Б.** Robokassa («Робочеки СМЗ») или Prodamus — официальные авточеки, но только для платежей через них. Нужно заново проверять, пропустят ли они VPN-сервис.
- **В.** ИП + онлайн-касса (обычные чеки 54-ФЗ на почту). Отдельная регистрация и расходы, на старте избыточно.
Решение — за владельцем.

### Автоотправка чеков ЮKassa — проверено 2026-10-24

В интернете пишут, что ЮKassa сама отправляет чеки в «Мой налог» за ~1%. **Это устарело.** В истории изменений API ЮKassa (https://yookassa.ru/developers/using-api/changelog) есть две записи. 27.09.2022: «Самозанятые теперь могут проводить платежи с автоматической регистрацией чека в сервисе Мой налог». 23.12.2025: «С 29 декабря 2025 года ЮKassa прекращает поддержку сервисов для самозанятых: чеки для самозанятых при платежах и возвратах». Это же подтвердили обе службы ЮKassa в ответах владельцу 2026-10-22 (задача 17). На странице для самозанятых (https://yookassa.ru/platezhi-dlya-samozanyatyh/) автоотправка больше не упоминается.

Вывод: у ЮKassa встроенной автоотправки нет. Варианты А/Б/В выше остаются в силе. Для варианта А есть готовый открытый проект https://github.com/grandvan709/yookassa-to-mynalog: он появился ровно из-за этого отключения и работает через вход в веб-кабинет lknpd.nalog.ru, то есть через тот же неофициальный интерфейс.

### Решение владельца и проверка требований (2026-10-24)

- Владелец: **самописные чеки не делаем** (вариант А отпадает). Нужен сервис, который сам формирует чеки и аннулирует их при возвратах. Рассматриваем **Robokassa + «Робочеки СМЗ»** (бесплатный, официальный сервис для самозанятых). Письмо — `drafts/pismo-robokassa.md`.
- Требования на текущую дату. Обязанность выдать чек через «Мой налог» по-прежнему действует: ст. 14 422-ФЗ, штраф по ст. 129.13 НК — 20% суммы, не меньше 200 ₽, повторно — 100%. Режим НПД продлён до 31.12.2028; ставки и лимит не менялись. Изменения с 01.10.2026 (289-ФЗ о платформенной экономике) касаются работы через цифровые платформы на одного заказчика, к нам не относятся. ЮKassa отключила автоотправку чеков 29.12.2025 по своему решению, а не потому, что чеки отменили.
- Важно: даже с «Робочеками» по закону за чек отвечает сам самозанятый. Сервис делает работу, но раз в месяц нужно сверять отчёт Robokassa с чеками в «Мой налог».
- Уточнить у Robokassa: аннулируется ли чек автоматически при возврате, частичные возвраты, СБП, что при сбое. Публичных подтверждений не нашли. Готовых VPN-ботов именно на Robokassa в открытых источниках не нашли; есть официальная интеграция Robokassa с Telegram-ботами (github.com/robokassa/telegram-pay).
