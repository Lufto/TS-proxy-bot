**Тема:** Предварительная проверка проекта перед подключением (самозанятый): прокси-сервис по подписке через Telegram-бота

Здравствуйте!

Я самозанятый (НПД) и планирую подключить ЮKassa. Прежде чем подавать заявку, прошу оценить мой проект и подсказать, подходит ли он для подключения.

**Что за сервис.** TS Proxy (сайт ts-proxy.com) — прокси-сервис с шифрованием трафика. Клиент получает по подписке доступ к нашим удалённым серверам: его интернет-трафик шифруется и проходит через наш сервер. Это защищает данные в публичных сетях Wi-Fi и скрывает IP-адрес клиента. Для подключения клиент использует бесплатные сторонние приложения (Happ, v2RayTun) для iOS, Android, Windows и macOS, протокол — VLESS. Мы не рекламируем и не обещаем доступ к ограниченным ресурсам; в пользовательском соглашении запрещено использование сервиса для незаконной деятельности, нарушители отключаются.

**Тарифы (подписка):** 1 месяц — 150 ₽, 3 месяца — 405 ₽, 6 месяцев — 765 ₽, 12 месяцев — 1476 ₽. Есть бесплатный пробный период 7 дней.

**Как происходит продажа.** Через Telegram-бота: клиент выбирает тариф → бот создаёт платёж и даёт ссылку на страницу оплаты → после успешной оплаты бот автоматически выдаёт клиенту персональную ссылку для подключения и срок доступа. Возвраты — по условиям пользовательского соглашения, за неиспользованные дни.

**Сайт** ts-proxy.com: описание сервиса, тарифы, порядок получения доступа после оплаты, пользовательское соглашение, условия возврата, политика обработки персональных данных, контакты, ФИО и ИНН.
