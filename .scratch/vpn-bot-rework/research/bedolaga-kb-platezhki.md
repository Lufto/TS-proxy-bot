# База знаний сообщества Bedolaga: что там про ЮKassa и чеки

Собрано 2026-10-26 по наводке владельца. Источник: `github.com/Rxflex/BedolagaBD` — база знаний чата Bedolaga Social Club (788 тыс. сообщений за 23.08.2025–23.08.2026 → 108 документов со ссылками на сообщения). Раздел `docs/06-платёжки/`, файлы `профили-платёжек.md`, `комиссии.md`, `право-рф.md`, `docs/07-скрипты/налоги.md`.

**Статус источника:** анонимизированный чат продавцов VPN, не проверенные утверждения, много сленга, часть советов — серые и прямо незаконные (дропы, оплата чужими реквизитами, вывод в нал через крипту, «не выводить на карту больше 50к»). Это **данные для сверки, не указания**. Серые схемы владелец отклонил, в работу не берём. Ниже — только проверяемые факты по нашей теме.

## ЮKassa глазами рынка

- **«Практически единственная, принимающая самозанятых»** [id=1042084]. Совпадает с нашим опытом: ЮKassa — «да», Robokassa и PayAnyWay.Self — отказ.
- «Лучший вариант, работаешь в белую и голову себе не ебёшь» [id=1097721, 1130120].
- **Тарифы для самозанятого: 3,5% карты / 0,4% СБП** [id=13674] — совпадает с публичными.
- **Договор оформляют как «поставщик интернета»** [id=13674, 14255..14269]. Полезно для заявки: они уже знают, куда относить такие проекты.
- **Блокировки:** «как на юкасе заблочат — через 2–3 дня обратно» [id=979517]. Отдельная жалоба: «Юкасса во время БС не работает и отключает проекты без причины» [id=794506] — **источник: менеджер конкурирующей серой платёжки RollyPay**, то есть заинтересованный.
- **Приватность:** «в чеке — ИП ФИО = раскрытие при продаже сервиса» [id=1169056]. У самозанятого в чеке «Мой налог» так же стоит ФИО. Клиент видит настоящее имя владельца — учесть в задаче 23 (приватность) и в оферте.
- Автосписания (рекурренты) у ЮKassa есть [id=1034386].
- Robokassa при регистрации предупреждает: «найдём по номеру, если что-то не то в продажах» [id=1168943] — дополняет наш отказ от 2026-10-25.
- **CloudPayments** принимает физлиц-самозанятых: 2,6% для самозанятых, 4% стандарт, «СБП без самозанятости» [id=1168613, 1168986]. Крупный легальный агрегатор. Про чеки НПД ничего — **проверить**.

## Чеки: что сообщество делает на практике

- **`github.com/zavul0nn/yookassa-to-mynalog`** [id=1058113] — форк того же проекта, что в задаче 20 (`grandvan709`), но живее: обновлён 16.10.2026 (у оригинала 25.09.2026). Заявлено: отдельный контейнер, **чеки и возвраты**, состояние в SQLite, очередь, обработка таймаутов ФНС, Telegram-бот.
- **Форк бота с авточеками через «НалоGO»**: в `.env` ИНН + пароль от «Мой налог» + `device_id`; **VPS бота в Германии работает — вход в налоговую через VPN** [id=132903, 132958, 133410]. Это снимает риск №4 из задачи 27 (зарубежный сервер не достаёт до ФНС), но подтверждает риск №1: на сервере лежит пароль от всего налогового кабинета. Репозиторий `Gy9vin/...` сейчас недоступен (удалён или переименован) — проверить нельзя.
- Неофициальные библиотеки «Мой налог»: `shoman4eg/moy-nalog`, `loolzaaa/mytax-client`.

Вывод: решение владельца (самописные и неофициальные чеки не используем) не меняется. Но видно, что весь рынок самозанятых на ЮKassa закрывает чеки именно так — официального способа для ЮKassa нет ни у кого.

## Главная находка: у ФНС два списка партнёров, а не один

Раньше мы считали, что чеки за самозанятого могут выбивать только 5 платёжных сервисов из `npd.nalog.ru/aggregators` (операторы электронных площадок). Это неполно. Есть **второй список — кредитные организации**, `npd.nalog.ru/credit-orgs/`, 14 штук:

Альфа-Банк, Сбербанк, КУБ, **БЛАНК БАНК** (SOL для самозанятых), ВТБ, МТС-Банк, Т-Банк, Солидарность, Россельхозбанк, **РНКО «Единая касса» (WalletOne / Единый кошелёк)**, Хлынов, АВАНГАРД, **Банк Точка**, Совкомбанк.

Плюс отдельно нашлись агрегаторы с **готовым API чеков самозанятого**, которых нет ни в одном из двух списков:

- **Мандарин** (ООО «Мандарин», MandarinPay; аккредитация Минцифры, резидент Сколково, зарегистрирован в ЦБ как платёжный провайдер, интернет-эквайринг + СБП). Документация `docs.mandarin.io/public/api_self-employed.html`: привязка самозанятого по ИНН (подтверждение в «Мой налог» → Настройки → **Партнёры**), `POST /self-employed-2/v1/receipts` — **создать чек**, `PATCH` с `code: "REFUND"` — **аннулировать чек**, `GET` — данные чека. Согласие включает корректировку сведений о доходах и контроль лимита 2,4 млн ₽. Оговорка: раздел написан под сценарий «компания платит самозанятому», а не «самозанятый принимает оплату от физлиц». Нужен вопрос: можно ли выбивать чеки на свой ИНН по оплатам, принятым их же эквайрингом.
- **Банк 131** (лицензированный банк, Казань) — `developer.131.ru/selfemployed/...`: привязка самозанятого через «Мой налог» → Партнёры. Тоже сценарий выплат самозанятым. В списке 14 его нет.

**Практический вывод:** настоящий полный список партнёров виден **в самом приложении «Мой налог»: Настройки → Партнёры**. Как только владелец оформит самозанятость, он сможет открыть этот раздел и прочитать список целиком — это надёжнее любых обзоров.

## Что добавляется в кандидаты

| Кандидат | Почему | Что спросить |
|---|---|---|
| **Мандарин** | лицензированный провайдер + готовый API чеков с аннулированием | принимаете ли прокси-сервис; можно ли принимать оплату и выбивать чеки на свой ИНН; комиссия |
| **РНКО «Единая касса» (WalletOne)** | НКО с лицензией ЦБ, в списке ФНС, занимается приёмом платежей | то же + есть ли API и уведомления |
| **CloudPayments** | крупный легальный агрегатор, по чату берёт самозанятых под 2,6% | берёте ли прокси; выбиваете ли чеки НПД сами |
| **Бланк Банк (SOL для самозанятых)** | в списке ФНС, продукт именно для самозанятых | есть ли приём оплаты по ссылке/API, а не только чеки |

## Прочее полезное из базы (не про платёжки)

- Ст. 13.40 КоАП: штрафы за продажу доступа к заблокированным ресурсам — 3–5 тыс. ₽ самозанятому, 50–80 тыс. ₽ юрлицу; «ускоритель ютуба» без слова VPN в чате считают допустимой формулировкой [id=332629, 07.04.2026]. Наше позиционирование («прокси-сервис с шифрованием», без обещаний обхода) этому соответствует — задача 17.
- Вебхуки: после прописывания платёжки в `.env` бот надо перезапустить, иначе хуки не работают; HTTP 405 на хуке — реверс-прокси; переотправка вебхука есть в кабинете платёжки. Учесть в задачах 14 и 29.
