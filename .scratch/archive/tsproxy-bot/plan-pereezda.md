**Не переносим:** Amnezia WireGuard, frp, openflux, Minecraft, Mindustry (решение владельца). Они есть в бэкапе 2026-10-31, кроме мира Minecraft.

## Что почувствуют клиенты

- **Панель и страница подписки** недоступны ~15 минут (этап 3). Прокси в это время **работают**: ноды продолжают обслуживать клиентов без панели.
- **Подключения.** В подписке 5 адресов указывают прямо на IP Zomro. После этапа 4 подписка выдаёт новый адрес. Приложение берёт его при обновлении подписки (интервал с 16:00 — 2 часа; раньше было 12). **Пока Zomro жив, старые адреса тоже работают** — старая нода продолжает обслуживать клиентов с последним списком пользователей. Когда Zomro выключится, у кого подписка не обновилась — перестанет работать «Германия», пока не обновит подписку. «Германия 2» работает у всех.
- После переезда владелец пишет клиентам (текст в конце).

## Этап 2. Боты (~20 мин, простой каждого бота ~1 минута)

Один токен Telegram нельзя запускать в двух местах одновременно, поэтому: настроить на новом → остановить на Zomro → забрать свежие данные → запустить на новом.

- [ ] Скопировать `/opt/pybots` (без старого окружения Python) и `/opt/rathole/server.toml`.
- [ ] Для каждого бота — своё окружение Python с теми же версиями библиотек, что на Zomro (`aiogram 3.31.0`, `aiohttp`, `google-genai 2.25.0`). Если что-то не заработает на Python 3.14 — ставим отдельный Python 3.12 только для ботов.
- [ ] Службы `vombot` и `furgpt`: запуск при старте сервера, перезапуск после падения, журнал в `journalctl`.
- [ ] Переключение: остановить бота в tmux на Zomro → докопировать его данные (`markov_data.pkl`, `kudos_data.pkl` у `vombot` меняются постоянно) → запустить службу на новом.
- [ ] Проверка: оба бота отвечают в Telegram, в журнале нет ошибок.

Замечание: токены ботов и ключ Gemini записаны прямо в коде. Переносим как есть; вынести в отдельный файл с закрытыми правами — в плане защиты.

Откат: остановить службу на новом, снова запустить в tmux на Zomro.

## Сколько времени

Всего ~2,5 часа работы. Этапы 1–2 можно начинать сразу. Этапы 3–4 лучше делать подряд, в тихое время, и **закончить минимум за 1–2 часа до отключения Zomro**, чтобы приложения успели обновить подписку, пока старые адреса ещё работают.
