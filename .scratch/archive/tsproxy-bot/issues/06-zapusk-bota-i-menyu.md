# Запуск бота, меню, инструкции, «Подключиться»

Type: task
Status: resolved
Blocked by: 01, 05

## Что сделать

aiogram 3 + FastAPI в одном процессе. На Mac — polling (бот снимает webhook), на сервере — webhook с `secret_token`. `/start`, меню в одном сообщении, «О сервисе», «Инструкции», «🚀 Подключиться», «📋 Скопировать ссылку», команды `/profile` `/buy` `/support`. Пометка «заблокировал бота». Ограничение частоты нажатий. Первая версия текстов.

## Готово, когда

- Бот отвечает с Mac.
- Тест: апдейт без `secret_token` отклоняется; чужие `callback_data` не дают доступа к чужим данным.

Решения: задачи 09, 10; security-audit R01, §4.3 (в `../vpn-bot-rework/issues/`). Спецификация — `../spec.md`.

## Comments

### 2026-10-24 — сделано (агент); живой прогон с Telegram — за ведущим

**Как запустить на Mac.**
1. В `.env`: `RUN_MODE=dev`, `BOT_TOKEN`, `REMNAWAVE_TOKEN` (токен разработки), `ADMIN_IDS`, `ADMIN_CHAT_ID`, `ALERTS_THREAD_ID`, `BACKUPS_THREAD_ID`. Адрес и секрет вебхука в dev не нужны.
2. `uv sync`, затем `uv run alembic upgrade head` (создаёт `data/tsproxy.db`).
3. `uv run tsproxy`. Бот проверяет версию панели, ставит команды в меню Telegram, **снимает webhook** (`deleteWebhook`, накопленные сообщения не выбрасывает) и получает сообщения через polling. Заодно поднимается веб-сервер на `127.0.0.1:8080` — в dev на нём пока ничего нет.
4. Остановка — `Ctrl+C`: бот дорабатывает текущие сообщения, закрывает соединения с Telegram, Remnawave и базой.

Важно: тот же бот на Mac и на сервере одновременно не запускать — запуск на Mac снимет webhook сервера.

**Сервер (`RUN_MODE=prod`).** Новые настройки: `PUBLIC_BASE_URL` (только `https://`), `TELEGRAM_WEBHOOK_SECRET` (32–256 символов `A-Za-z0-9_-`, например `openssl rand -hex 32`), `WEB_HOST`, `WEB_PORT`, `REMNAWAVE_SQUAD` (squad для новых аккаунтов, по умолчанию `Default-Squad` — подтвердить при подключении). Без адреса или секрета бот в prod не стартует. При старте бот ставит webhook на `PUBLIC_BASE_URL/telegram/webhook` (в адресе нет токена) с `secret_token`. Запрос без заголовка `X-Telegram-Bot-Api-Secret-Token` или с неверным значением получает 403 (сравнение за постоянное время, `hmac.compare_digest`). Чтобы сменить секрет, достаточно вписать новый и перезапустить бота.

**Что умеет бот.**
- `/start` — записывает клиента (Telegram ID, имя, @username, дата первого визита) или обновляет имя, **снимает пометку «заблокировал бота»**, присылает меню.
- Меню — одно сообщение, экраны меняются в нём же: «🚀 Подключиться», «🎁 Попробовать бесплатно» (только если пробный не брал), «💳 Тарифы», «👤 Мой профиль», «📖 Инструкции», «💬 Поддержка», «ℹ️ О сервисе». Если старое сообщение уже нельзя изменить, бот присылает новое.
- Команды `/profile`, `/buy`, `/support` открывают те же экраны новым сообщением; они же видны в меню команд Telegram.
- «🚀 Подключиться» — бот спрашивает Remnawave о прокси-аккаунте **нажавшего** (по `from_user.id`) и показывает кнопки «Открыть страницу подключения» (ссылка подписки) и «📋 Скопировать ссылку» (копирует ссылку в одно нажатие), срок по Москве. Подписка закончилась — подсказывает продлить. Аккаунта нет — «подписки пока нет» и кнопка пробного (если не брал) и тарифов. Панель не отвечает — извинение клиенту и тревога в «🚨 Тревоги» (склеивается).
- «📖 Инструкции» — выбор устройства (iPhone/iPad, Android, Windows, macOS), на каждое три шага: Happ основное, v2RayTun запасное. Ссылок на магазины нет — проверенных ссылок у нас нет, добавить вместе со скриншотами (сайт, задача 25).
- «ℹ️ О сервисе» — описание из черновика позиционирования и строка про условия использования со ссылкой `https://ts-proxy.com/terms` (страница появится в задаче 25).
- Любое другое сообщение — подсказка «пока понимаю только кнопки» (станет обращением в поддержку в задаче 16). Неизвестная или подделанная кнопка — «кнопка устарела, откройте /start».
- **Пометка «заблокировал бота»** ставится, когда Telegram отвечает «бот заблокирован» на отправку (все сообщения клиенту идут через `ClientDelivery`) или когда клиент нажимает «Заблокировать» (Telegram присылает `my_chat_member`). Ставится один раз (первая дата сохраняется). Снимается при `/start`.
- **Ограничение частоты:** на клиента 5 действий подряд, дальше не чаще 30 в минуту (кнопки и сообщения в личке). Лишняя кнопка получает всплывающее «Не так быстро», лишние сообщения — одно предупреждение, остальное молча не обрабатывается. Администраторы не ограничены. Счётчики в памяти.
- **Чужие чаты (R19):** если бота добавили в любую группу или канал, кроме группы администраторов (или оттуда пришло сообщение), бот выходит.
- **Ошибки в обработчиках** — в лог с трассировкой, тревога «Ошибка в боте: <тип>» (склеивается по типу), клиенту — «что-то пошло не так».
- Фоновые задачи: пока одна — сводки повторов тревог раз в минуту (`Alerter.flush_repeats`).

**Заглушки (текст «скоро» и кнопка «В меню»):**

**Для следующих задач.**
- Сборка всего приложения — `src/tsproxy/app.py` (`build_application`, `run_application`). Зависимости обработчиков — `BotContext` (`bot/context.py`), обработчик получает его аргументом `ctx`. Новые роутеры (админка, поддержка) передаются в `create_dispatcher(..., extra_routers=[...])` — они встают перед «запасным» роутером.
- Админка: фильтр `AdminFilter(AdminAccess(...))` из `bot/admin.py` пропускает только `ADMIN_IDS` и только в группе администраторов — ставить на весь роутер админки.
- Сообщения клиенту — только через `ctx.delivery.send(...)` / `ctx.delivery.call(...)`, чтобы срабатывала пометка «заблокировал». Рассылки и уведомления должны пропускать клиентов с `bot_blocked_at`.
- Фоновые задачи — `PeriodicJob` в `PeriodicJobs` в `app.py`.
- Подделка Telegram для тестов — `bot/fakes.py` (`FakeTelegramSession`).

**Тексты.** `content/texts.yaml` — новые группы `commands`, `buttons`, `connect`, `trial`/`tariffs`/`profile`/`support` (заглушки), `about`, `instructions`, `throttle`, `errors`, `fallback`; все ключи обязательны при запуске (`REQUIRED_TEXTS`). В `admin_texts.yaml` — тревоги `remnawave_unavailable`, `remnawave_at_start`, `bot_error`. Тексты первой версии — на вычитку владельцу.

**Зависимости:** `aiogram` 3.31, `fastapi` 0.162, `uvicorn[standard]` 0.54; `httpx` остался `<0.28` (aiogram работает через aiohttp, конфликта с `remnawave-api` нет).
