## Запускает владелец (агенту заблокированы правки на серверах)

Система безопасности Claude Code перестала пропускать изменения на серверах (файрвол, cron). Скрипты готовы в `ops/server-hardening/`, запуск — с Mac, из папки проекта:

1. **Файрвол** (главное из оставшегося). Через 10 минут сам выключится, если не отменить страховку — агент за это время проверяет подключения.
   - `ssh tsp 'bash -s' < ops/server-hardening/firewall-main.sh` — открыты 22, 443, 8443, 2053, 2083; 8080 и 2052 — только для Cloudflare; 2222 — только для контейнеров панели.
   - `ssh tsp2 'bash -s' < ops/server-hardening/firewall-germany2.sh` — открыты 22, 443, 8444; 2222 — только для основного сервера.
2. **Тревоги «диск > 85%», «памяти < 10%»** — по одной команде на сервер, см. шапку `ops/server-hardening/install-resource-check.sh`.
3. **Удалить `/root/restore` на основном** — там расшифрованная копия базы панели (`db.sql.gz`, все клиенты) и `panel.env` с секретами после переезда. Зашифрованные копии есть в Telegram и на Mac. `ssh tsp 'rm -rf /root/restore'`
4. **Перезагрузка основного** — 64 обновления. Клиенты на «Германии 2» не заметят, остальные — ~2 минуты без связи; лучше ночью: `ssh tsp 'apt-get update && apt-get -y upgrade --with-new-pkgs && systemctl reboot'`.
