### 1. Что за сервис

**TS Proxy** (сайт ts-proxy.com) — прокси-сервис с шифрованием трафика, доступ по подписке.

Как это работает технически:
- клиент получает персональную ссылку для подключения к нашим удалённым серверам;
- ссылку он добавляет в бесплатное стороннее приложение — Happ или v2RayTun (iOS, Android, Windows, macOS); протокол подключения — VLESS;
- после подключения интернет-трафик клиента шифруется и проходит через наш сервер.

Для клиента это даёт защиту данных в публичных сетях Wi-Fi (кафе, аэропорты, гостиницы) и скрытие его IP-адреса от сайтов и сервисов.

Мы **не рекламируем и не обещаем доступ к ограниченным ресурсам**. В пользовательском соглашении прямо запрещено использовать сервис для незаконной деятельности (а также для спама, атак, распространения вредоносного ПО, нарушения авторских прав и перепродажи доступа); при нарушении доступ отключается. Пользователь самостоятельно отвечает за соблюдение законодательства при использовании сервиса.

### 4. Как происходит продажа и оплата

Продажа идёт через Telegram-бота:
1. клиент выбирает тариф в боте;
2. бот создаёт платёж через API ЮKassa (по номеру заказа, с ключом идемпотентности) и даёт клиенту ссылку на платёжную форму ЮKassa;
3. клиент оплачивает по СБП или банковской картой на странице ЮKassa;
4. после оплаты клиент возвращается в бота (через страницу ts-proxy.com/paid);
5. бот получает HTTP-уведомление от ЮKassa, перепроверяет статус платежа через API и **автоматически** выдаёт клиенту доступ: персональную ссылку для подключения и срок действия подписки.

Неоплаченный платёж через час отменяется. Каждая оплата засчитывается ровно один раз.

### 5. Возвраты и поддержка

- Возврат возможен в течение 30 дней с оплаты, если сервис не работал по нашей вине и поддержка не смогла помочь, — за неиспользованные полные дни, не чаще одного раза в полгода на клиента. Возврат делаем через ЮKassa на то же средство оплаты.
- Поддержка — прямо в Telegram-боте, ответы на обращения клиентов.
