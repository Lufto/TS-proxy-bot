### Работа с попапами

Главный компонент Popups осуществляет функцию открытия модального окна

Компоненты попапов должны находиться в папке `"@/widgets/popups/название_компонента/index.tsx"`.

Вызов попапа осуществляется через функцию openPopup, получаемую через провайдер usePopupsEngineProvider.

Функция принимает объект, обязательное свойство которого - variant - название попапа, второй popupProps - пропсы открываемого попапа

Закрытие попапа осуществляется через функции closePopup или closeAllPopups, получаемые через провайдер usePopupsEngineProvider

{ TPEComponentWrapper } from '@idem.agency/popups-engine' — дженерик для типизации попапов. Передаёт в компонент служебные пропсы (например, closePopup).
