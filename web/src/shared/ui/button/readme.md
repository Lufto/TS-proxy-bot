# Button

Кнопка кита «Манифест». С `url` — ссылка (внешние открываются в новой вкладке), без `url` — кнопка. Устройство ссылки/кнопки и отключённой ссылки взято из «Ссылки» хранилища компонентов.

## Пропсы

- `variant` — `primary` (оранжевая, «Бегущая строка» и стрелка), `secondary` (светлая плашка, заливка уходит вниз), `ghost` (только текст)
- `size` — `l` (56 px) или `m` (44 px)
- `url`, `target` — адрес и target ссылки
- `arrow` — стрелка после надписи; по умолчанию только у `primary`
- `disabled`, `submit`, `onClick`

Надпись передаётся строкой в `children`: из неё собирается копия для «Бегущей строки».
