# Link

Текстовая ссылка из хранилища компонентов (`component-storage/components/link`, исходно ascot-front), перекрашенная под «Манифест». Три варианта линии собраны в один компонент.

## Пропсы

- `underline` — `hover` (линия выезжает при наведении, по умолчанию), `solid` (постоянная оранжевая — для ссылок внутри текста), `none`
- `color` — `cream` (по умолчанию, при наведении оранжевая), `muted` (серая, при наведении светлая), `accent` (оранжевая)
- `arrow` — стрелка после текста, сдвигается при наведении
- `typography` — класс типографики (`t-body`, `t-caption`…); без него шрифт наследуется
- `url`, `target`, `rel`, `disabled`, `submit`, `onClick` — как у исходной «Ссылки»: без `url` рендерится кнопка
