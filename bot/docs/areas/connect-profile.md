# Подключение, профиль и меню

Что клиент видит каждый день: меню, «Подключиться», «Мой профиль», «Мои устройства», инструкции. Пробный — [trial.md](trial.md), сроки и напоминания — [access.md](access.md).

## Правила

- **Меню в одном сообщении**: экраны переключаются кнопками. Команды: `/start`, `/profile`, `/buy`, `/support`, `/help` (список команд клиента; в группе администраторов `/help` — команды админки). Обработчики работают только в личном чате.
- **Строка статуса над главным меню**: «✅ Активна до …», «⛔ Закончилась», пробный — с датой (тот же статус, что в профиле). Меню спрашивает панель не дольше 3 секунд; нет прокси-аккаунта, панель не ответила или не успела — меню без строки, без ошибки и без тревоги.
- **`/start` с параметром**: `?start=support` открывает поддержку (кнопки на сайте), `?start=devices` — «Мои устройства» (кнопка на странице подписки).
- **«Подключиться»** открывает страницу подписки `https://sub.ts-proxy.com/<код>`, есть кнопка «Скопировать ссылку». Прокси-аккаунт ищется по Telegram ID нажавшего.
- **Панель не ответила на «Подключиться»** — клиенту «ссылку пришлём сюда», и фоновая задача сама присылает экран подключения, когда панель ожила. Ждёт не дольше суток. Тревога «Remnawave не отвечает» уходит администраторам.
- **Профиль**: статус словами, до какой даты и сколько осталось, «устройства N из 3», трафик — только у пробного.
- **Устройства**: список (модель, ОС, когда подключено) и «Удалить». Удаляется только устройство из списка нажавшего. Удаление лишь освобождает место: приложение с настройками может работать до обновления подписки.
- **«Перевыпустить ссылку»** — клиент сам, не чаще раза в сутки (по журналу событий; перевыпуск администратором попытку не расходует). Новая ссылка ломает подписку на всех устройствах — клиент добавляет её заново.
- **Кнопки клиента — без смайликов** (смайлики — только со смыслом в тексте: ✅/⛔ в статусе, 🎁 в заголовке). Цвет (Bot API `style`) — в `BUTTON_STYLES` (`bot/screens.py`): «Подключиться» зелёная, «Удалить», «Перевыпустить ссылку» и «Да, перевыпустить» красные, остальные обычные. Кнопки админки не меняются.
- **Инструкции**: Happ — основное приложение на всех платформах, запасные — по устройствам. Подробно со скриншотами — на сайте.
- **Клиент заблокировал бота** — пометка, ему не шлём уведомления и рассылки; снимается при новом `/start`.
- **«Печатает…»**: пока бот ждёт панель или платёжку (подключение, пробный, профиль, устройства, перевыпуск, счёт СБП и звёздами, «Проверить оплату»), у клиента в шапке чата «печатает…». Обработчик помечается флагом `TYPING`; ошибка отправки «печатает…» действие не ломает.
- **Ограничение частоты** нажатий на клиента — «ведро с жетонами» в памяти (`bot/throttling.py`).

## Где в коде

| Что | Файл |
|---|---|
| Меню, `/start`, инструкции | `bot/menu.py`, `bot/screens.py` |
| «Подключиться», ожидание ссылки | `bot/connect.py`, `services/connect_waits.py` |
| Профиль и устройства | `bot/profile.py`, `bot/profile_screens.py`, `services/profile.py`, `domain/profile.py` |
| Перевыпуск ссылки | `services/link_revoke.py`, `domain/link_revoke.py` |
| Запись клиента, «заблокировал бота» | `services/clients.py`, `bot/chats.py`, `bot/delivery.py` |
| Частота нажатий | `bot/throttling.py` |
| «Печатает…» при ожидании | `bot/chat_typing.py` |
| Обёртка Remnawave | `integrations/remnawave.py`, `integrations/remnawave_types.py` |

Пути — от `bot/src/tsproxy/`.

## Тексты

`bot/content/client/`: `menu.yaml` (меню, «О сервисе», ошибки), `connect.yaml` (подключение и инструкции), `profile.yaml` (профиль, устройства, перевыпуск), `buttons.yaml`, `commands.yaml`. Ссылки на приложения — `config/site.yaml`.
