# Части бота

Бот TS Proxy продаёт подписку на прокси и обслуживает клиентов без ручной работы. Описание разбито на части: для работы над частью читай её страницу, а не всё подряд.

Каждая страница — это правила (как работает сейчас), где код, где тексты и что открыто. Подробности шага — в шапке (docstring) модуля из таблицы «Где в коде»: шапка и есть спецификация модуля и меняется вместе с кодом.

Недоделки и опасные места всех частей — в [../todo.md](../todo.md). Термины — в `GLOSSARY.md` в корне репозитория. Правила кода — [../python-rules.md](../python-rules.md).

## Правила для всех частей

- **Нынешних клиентов панели не трогаем.** В Remnawave есть аккаунты, заведённые вручную. Бот работает только со своими аккаунтами: `tg_<telegram_id>` в бою, `dev_<id>` в squad `test` в разработке. Проверка стоит в обёртке Remnawave (`AccountGuard`), а не только в вызывающем коде.
- **Один клиент Telegram — один прокси-аккаунт.** Покупка продлевает срок.
- **Срок, статус, трафик и устройства знает только Remnawave.** В базе бота — только то, чего нет в панели.
- **Срок меняется только командой «поставь срок до X»**, а не «добавь N дней», и под блокировкой срока клиента (`term_locks`). Так повтор после сбоя не даёт лишних дней.
- **Каждая оплата засчитывается ровно один раз.**
- **Клиент — всегда `from_user.id` нажавшего.** Кнопки несут только «что открыть», а не «чьё».
- **Действия администратора** — только от `ADMIN_IDS` и только в группе администраторов (`AdminFilter` на обработчике). Каждое действие пишется в журнал событий.
- **Слово «VPN» не используем** — только «прокси». Не обещаем доступ к заблокированным ресурсам.
- **Тексты — только в `bot/content/`**, ни одного текста в коде. Только русский. Даты для клиента — по Москве: «10.12.2026, 18:00 МСК».
- **Структура базы меняется только с согласия владельца.**
- **На серверах ничего не делаем без «ок» владельца на каждое действие.**
