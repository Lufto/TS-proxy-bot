# Админка

Команды и кнопки в группе администраторов. Рассылка и объявление — [broadcast.md](broadcast.md), возвраты и перенос — [refunds.md](refunds.md), компенсация — [compensation.md](compensation.md).

## Команды

| Команда | Что делает |
|---|---|
| `/client 123` или `/client @name` | карточка клиента: подписка, оплаты, пробный, устройства; кнопки действий |
| `/give 123 30` | выдать или продлить на N дней (не больше 400 за раз), с подтверждением |
| `/trials` | включены ли пробные, кнопка переключения |
| `/banner` | плашка о неполадках на сайте ts-proxy.com: поставить или снять |
| `/stats` | оплаты, подписки, пробный → оплата, обращения, заблокировавшие бота |
| `/proof 123` | доказательство оказания услуги по заказу — файл для спора с платёжкой |
| ~~`/transfer …`~~ | перенос подписки — отключён 2026-11-11 ([refunds.md](refunds.md)) |
| `/outages` | последние сбои нод с кнопками компенсации |
| `/broadcast`, `/announce` | рассылка и объявление ([broadcast.md](broadcast.md)) |
| `/help` | список команд админки (тот же текст, что у `/client` без запроса) |

## Правила

- **Права**: только `ADMIN_IDS` и только в группе администраторов, проверка на каждом обработчике. Бот сам выходит из чужих групп.
- **Поиск** — по Telegram ID или @username, **действие** — всегда по Telegram ID из карточки (@username мог смениться). Только клиенты бота: по чужому ID аккаунт не создаётся.
- **Ручная выдача** — с подтверждением: кнопка «✅ Да» несёт срок, который видел администратор. Срок уже другой (двойное нажатие, оплата) — ничего не делается. Клиенту приходит «Вам добавили N дней».
- **Каждое действие** — событие `ADMIN_ACTION` в журнале с Telegram ID администратора.
- **Статистика**: продажи по времени зачёта за вычетом возвратов по времени возврата; звёзды — отдельной строкой; живые подписки — из Remnawave (панель не ответила — строка «неизвестно», остальное из базы).
- **Плашка на сайте**: ставится и снимается только кнопкой (`/banner` или кнопка под тревогой «Remnawave не отвечает»). Сайт читает её через `/status`.
- **Панель не ответила** на действие — «⚠️ Панель Remnawave не ответила» (без причины и без тревоги — см. todo).
