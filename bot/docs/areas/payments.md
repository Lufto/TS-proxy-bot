# Оплата: СБП через Platega и звёзды Telegram

Как клиент покупает подписку и как бот засчитывает оплату. Выдача доступа после зачёта — [access.md](access.md), возвраты и споры через банк — [refunds.md](refunds.md), тревоги — [alerts.md](alerts.md).

Подробности каждого шага — в шапке (docstring) модуля из таблицы ниже. Шапка и есть спецификация, здесь только то, что нужно, чтобы найти нужное место.

## Правила

- **Платёжка — Platega, СБП** (комиссия 8%, деньги приходят через 3 дня, чеков нет). Второй способ — **звёзды Telegram**. Автопродления нет.
- **Каждая оплата засчитывается ровно один раз.** Все пути (уведомление, «🔄 Проверить оплату», фоновая проверка, «Купить», сверка) сходятся в `CreditingService.credit`.
- **Уведомлению не верим, спрашиваем платёжку.** Уведомления принимаем от кого угодно, без фильтра по IP. Нет такого заказа — подделка: одна запись в журнале и одна тревога, к платёжке не идём.
- **Подтверждённая оплата засчитывается всегда**, даже по отменённому заказу и даже через сутки.
- **Цена и дни — только из `config/tariffs.yaml`**, кнопка несёт лишь id тарифа. Тарифы: 30 дней — 150 ₽, 90 — 405 ₽, 180 — 765 ₽, 365 — 1440 ₽. Скрытого тестового тарифа нет. Цена в звёздах = рубли / `stars_rub_rate` (сейчас 1,5).
- **Ссылка на оплату** живёт столько, сколько скажет Platega (обычно 30 минут), но не больше часа. Тот же тариф, пока ссылка жива, — та же ссылка.
- **Перед новой ссылкой** бот спрашивает платёжку о неоплаченных заказах клиента за сутки. Нашлась оплата — засчитать и ссылку не давать. Платёжка не ответила — ссылку тоже не давать.
- **Оплачено не столько, сколько стоит тариф** — срок пропорционально оплате плюс 2 часа, извинение клиенту, тревога.
- **Случайная двойная оплата** — дни складываются, пометка в «💰 Оплаты», клиенту: «если вторая оплата случайная, напишите в поддержку».
- **Звёзды, которые не подошли к заказу**, сразу возвращаются клиенту, администраторам — тревога.
- **Сверка раз в сутки** (09:00 МСК): все платежи Platega за сутки сравниваются с заказами, расхождения уходят одной тревогой.
- **Режимы** (`PAYMENTS_MODE`): `platega` — боевой; `fake` — поддельная платёжка для разработки, в `RUN_MODE=prod` не запускается; `off` — тарифы видны, купить нельзя, только пробный. Сейчас на сервере `off`.
- Признак «тестовый платёж» должен совпасть с `PLATEGA_TEST_ACCOUNT`: в бою засчитываются только настоящие платежи.

## Где в коде

| Что | Файл |
|---|---|
| Тарифы, заказ, ссылка на оплату, «нашлась прошлая оплата» | `services/orders.py` |
| Уведомления, «Проверить оплату», фоновая проверка | `services/payment_checks.py` |
| Зачёт (и выдача доступа) | `services/crediting.py` |
| Статус изменился после оплаты (спор, возврат мимо бота) | `services/payment_status.py` |
| Ежедневная сверка | `services/payment_reconciliation.py` |
| Звёзды: заказ, проверка перед оплатой, зачёт, возврат несовпавших | `services/stars.py`, `bot/stars.py`, `domain/stars.py` |
| Экраны тарифов и оплаты | `bot/tariffs.py` |
| Сообщения клиенту «✅ Оплачено», «доступ задерживается» | `bot/payments.py` |
| Адрес для уведомлений платёжки (ответы 200/400/413/500/503) | `web/payments.py` |
| Platega (HTTP, колбэк, возврат, выгрузка) | `integrations/platega.py` |
| Общий интерфейс платёжки | `integrations/payments_types.py` |
| Поддельная платёжка и скрипт «оплатить» | `integrations/fake_payments.py`, `scripts/simulate_payment.py` |
| Правила сумм, двойной оплаты, сверки | `domain/payments.py`, `domain/money.py` |

Пути — от `bot/src/tsproxy/`.

## Тексты

- Для клиента — `bot/content/client/`: `tariffs.yaml` (тарифы и звёзды), `payment.yaml`, `units.yaml`.
- Для администраторов — `bot/content/admin/payments.yaml` (сообщения в «💰 Оплаты»); тревоги — `bot/content/alerts/payments.yaml` (оплаты, выдача после оплаты), виды сбоя платёжки — `alerts/payments_failures.yaml`; звёзды и возвраты — `alerts/refunds.yaml`.

## Platega: что уходит в запросе

Email клиента передаётся: `metadata.user_email = <telegram_id>@telegram.org` (решение владельца 2026-10-31, включено в `app.py`, `send_customer_email=True`). Шапка `integrations/platega.py` говорит обратное («не передаём») — она устарела.
