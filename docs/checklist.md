# Ручной чеклист перед выкаткой

Проходится на **тестовом боте** перед каждой выкаткой. Сценарии сгруппированы по ролям: клиент, администратор, поддержка, сбои. Каждый пункт — «сделал → проверил результат». Если что-то не так — выкатку останавливаем.

Подготовка:
- [ ] Тестовый бот запущен через туннель, `.env` указывает на тестового бота и squad `test`.
- [ ] Есть два Telegram-аккаунта: «клиент» (не администратор) и «администратор».
- [ ] Автотесты прошли: `uv run pytest` — зелёные.

Чтобы не ждать днями, сроки у тестовых аккаунтов `dev_` выставляем короткими (минуты) через админку или панель.

---

## 1. Клиент: новый

- [ ] `/start` → приветствие с именем, главное меню; видна кнопка «🎁 Попробовать бесплатно».
- [ ] Команды в меню Telegram: `/start`, `/profile`, `/buy`, `/support`.
- [ ] «👤 Мой профиль» до любых действий → «Подписки нет», кнопки «Попробовать» и «Тарифы».
- [ ] «ℹ️ О сервисе» → текст без упоминания доступа к заблокированным сервисам; ссылка на условия использования.
- [ ] «📘 Инструкции» открываются, ссылки ведут на рабочие страницы.

## 2. Клиент: пробный период

- [ ] «🎁 Попробовать бесплатно» → «Пробный период на 7 дней активирован», кнопки «🚀 Подключиться», «📋 Скопировать ссылку», «Инструкции».
- [ ] В панели Remnawave появился аккаунт клиента: срок +7 дней, лимит трафика 7 ГБ, лимит устройств 3, squad верный.
- [ ] Повторно «Попробовать бесплатно» недоступно (кнопки нет или бот объясняет, что пробный уже был).
- [ ] Профиль: «🎁 Пробный период», дата окончания по МСК, «осталось N дней», трафик «X из 7 ГБ», устройства «0 из 3».
- [ ] «📋 Скопировать ссылку» копирует ссылку подписки в буфер.
- [ ] **Не подключался:** срок истёк → бот продлил на 3 дня и написал «пробный период истёк, но мы его продлили».
- [ ] **Не подключался:** после 5-го продления (итого 22 дня) → прощальное сообщение, больше продлений нет.
- [ ] **Подключался:** напоминание за день и за час до окончания, с кнопкой «Продлить»; после окончания продления нет, льготного периода нет.
- [ ] **Покупка во время пробного:** оплаченные дни добавились к остатку пробного периода.

## 3. Клиент: покупка

- [ ] «💳 Тарифы» → 4 тарифа, цены 150 / 405 / 765 / 1476 ₽, скидки −10% / −15% / −18% посчитаны верно.
- [ ] Выбор тарифа → экран оплаты: сумма, «ссылка действует 1 час», кнопки «Оплатить по СБП», «Проверить оплату», «Назад».
- [ ] Повторный выбор того же тарифа в течение часа → та же ссылка на оплату (новый счёт не создан).
- [ ] Выбор другого тарифа → новый счёт.
- [ ] Оплата (скрытый тестовый тариф или имитация уведомления) → бот **сам** прислал новое сообщение «✅ Оплачено, подписка до …» со ссылкой и инструкциями.
- [ ] После оплаты Cardlink вернул на `/paid`, страница открыла бота.
- [ ] «Проверить оплату» до оплаты → «оплата пока не найдена».
- [ ] Повторное уведомление об оплате (имитацией) → подписка второй раз **не** продлилась.
- [ ] Срок: новый клиент — от момента оплаты; активная подписка — от даты окончания; 1 мес = 30 дней, 3 = 90, 6 = 180, 12 = 365.

## 4. Клиент: продление, льготный период, отключение

- [ ] Напоминания за день и за час до окончания платной подписки, с кнопкой «Продлить».
- [ ] Срок вышел → VPN продолжает работать, сообщение о льготном периоде на 3 дня; в профиле «⏳ Льготный период — продлите до …».
- [ ] Каждые сутки льготного периода — напоминание.
- [ ] Покупка в льготный период → новый срок **от момента оплаты**, статус «✅ Активна».
- [ ] Не продлил → после льготного периода доступ отключён, одно финальное сообщение, дальше бот не пишет.
- [ ] Аккаунт в Remnawave **не удалён**; покупка после отключения → та же ссылка подписки, срок от момента оплаты.

## 5. Клиент: устройства

- [ ] Профиль показывает «N из 3».
- [ ] «📱 Мои устройства» → список (модель, ОС, когда подключено).
- [ ] «🗑 Удалить» → устройство исчезло из списка и из панели, счётчик уменьшился.
- [ ] 4-е устройство при лимите 3 не подключается; после удаления старого — подключается.

## 6. Клиент: поддержка

- [ ] «💬 Поддержка» → частые вопросы кнопками, ниже «Не нашли ответ — просто напишите».
- [ ] Любое обычное сообщение боту → «Обращение #N создано, ответим в ближайшее время».
- [ ] Фото, файл, голосовое — дошли в тему обращения; стикер — не пересылается.
- [ ] Больше 10 сообщений за минуту → бот просит подождать.
- [ ] Ответ поддержки пришёл от бота с подписью «Поддержка».
- [ ] Обращение закрыто → клиент получил «Обращение закрыто…». Новое сообщение в течение суток → то же обращение переоткрыто; позже → новое.

## 7. Клиент: возврат

- [ ] «↩️ Вернуть деньги» видна только если с оплаты ≤ 30 дней и за полгода возвратов не было; иначе бот объясняет, почему недоступно.
- [ ] Бот показывает условия и сумму за неиспользованные полные дни, просит причину.
- [ ] Создано обращение с пометкой «↩️ ВОЗВРАТ», уведомление в теме «↩️ Возвраты».
- [ ] Отказ администратора → клиент получил причину.
- [ ] Одобрение → после подтверждения подписка отключена.

## 8. Клиент: заблокировал бота

- [ ] Клиент заблокировал бота → уведомления и рассылки ему не уходят, в статистике он учтён.
- [ ] Разблокировал и нажал `/start` → пометка снята.

---

## 9. Администратор

- [ ] У клиента нет админских кнопок и команд; у администратора — есть.
- [ ] Найти клиента по Telegram ID и по @username → подписка, срок, платежи, пробный период.
- [ ] Вручную выдать/продлить подписку на N дней → срок в панели изменился, запись в журнале администраторов.
- [ ] Статистика: продажи за день и месяц, активные подписки, конверсия пробного, клиенты, заблокировавшие бота, обращения и среднее время ответа.
- [ ] Рассылка → дошла всем, кроме заблокировавших бота.
- [ ] Сбросить/повторно выдать пробный период клиенту.
- [ ] Удалить устройства клиента.
- [ ] Скрытый тариф «Тест — 15 ₽ / 1 день» виден только администратору.
- [ ] Каждое действие администратора видно в журнале: кто, что, когда.

## 10. Группа администраторов

- [ ] Темы «💰 Оплаты», «🚨 Тревоги», «↩️ Возвраты» закреплены сверху.
- [ ] Каждая оплата → сообщение в «💰 Оплаты».
- [ ] Новое обращение → новая тема с карточкой клиента (подписка, устройства, оплаты, пробный) и кнопками «➕ Продлить на N дней», «📱 Устройства».
- [ ] «🙋 Беру» → в теме видно, кто взял.
- [ ] Быстрые ответы → готовый текст ушёл клиенту.
- [ ] Сообщение с `//` → клиенту **не** ушло.
- [ ] Нет ответа больше часа → бот напомнил в теме.
- [ ] «✅ Закрыть» → тема закрыта, клиент уведомлён.

## 11. Сбои

- [ ] **Remnawave недоступна после оплаты** (имитация) → клиенту «Оплата получена, доступ подключается»; повторы каждую минуту; через 30 минут — тревога в «🚨 Тревоги»; заказ виден в админке.
- [ ] **Уведомление об оплате потерялось** (имитация: не отправлять) → фоновая проверка или «Проверить оплату» засчитали оплату.
- [ ] **Поддельное уведомление** (неверная подпись) → отклонено, подписка не продлена, тревога.
- [ ] **Оплата не на сумму тарифа** (имитация) → срок пересчитан пропорционально +2 часа, клиенту извинение, администраторам уведомление.
- [ ] **Нода Remnawave упала** → тревога; восстановилась → сообщение с длительностью простоя и кнопкой «Компенсировать»; по кнопке активным клиентам добавлено время простоя + 1 день, клиенты получили извинение.
- [ ] **Бот был выключен**, пока у клиента истёк срок → при запуске бот выдал пропущенный льготный период и отправил пропущенные сообщения.
- [ ] **Бот упал** → на сайте появилась плашка «Извините, у нас неполадки»; поднялся → плашка исчезла.

## 12. После выкатки на сервер (настоящие деньги)

- [ ] Администратор купил скрытый тариф «Тест — 15 ₽ / 1 день» по СБП.
- [ ] Пришло настоящее уведомление от платёжки, подпись прошла, сумма в уведомлении совпала с ожидаемой (сверить формат суммы и комиссию).
- [ ] Подписка продлилась, сообщение «✅ Оплачено» пришло, оплата появилась в «💰 Оплаты».
- [ ] Деньги видны в кабинете платёжки.
